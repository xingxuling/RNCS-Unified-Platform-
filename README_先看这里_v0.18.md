# RNCS＋Aetherworld v0.18：第三人称开放世界动作RPG垂直切片

本版第一次交付真实透视第三人称3D客户端，而不是2D/2.5D逻辑演示。

## 立即体验

直接打开根目录：`灰烬边境_第三人称3D_直接打开.html`

## 控制

- WASD / 方向键：移动
- 鼠标拖动：绕角色旋转第三人称相机
- 左键 / J：剑击
- Shift：闪避
- Tab：锁定
- R：声控或文字咏唱
- E：交互
- 1—5：快捷法术
- F5：保存

## 双客户端交付

1. WebGL：已经在 Chromium＋SwiftShader 中完成真实渲染和行为烟雾测试。
2. Godot 4.7：原生工程源码已完成并静态验证；当前容器没有Godot二进制，因此没有伪称完成Godot构建或导出。
