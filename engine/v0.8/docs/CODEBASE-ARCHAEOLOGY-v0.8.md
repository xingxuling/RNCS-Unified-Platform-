# Codebase Archaeology v0.8

The v0.7 mother project and GitHub main-95 already contained RSR authoritative frames, Network reconciliation, Capsule-Capsule, rotated OBB SAT, sub-step CCD, PBR, shadows and a WebGPU execution skeleton. Those capabilities were frozen and reused.

The minimum modification surface was therefore:

1. RSR playable-state stability: persistent contacts, spatial partitioning and production character traversal.
2. VSR asset presentation: glTF scene materialization, texture sampling and animation-only presentation state.
3. A vertical acceptance path proving two-client authority convergence and independent visual roots.

Network remained at v0.2 because it continued to carry the same RSR authoritative-state protocol rather than introducing a second physical-state model.
