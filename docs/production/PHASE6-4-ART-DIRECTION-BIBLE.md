# Phase 6.4 Art Direction Bible

## Visual thesis
A young-adult Anime character must read first as a coherent designed silhouette, second as a face/body with semantic regions, and only then as shaded/detail-rich media. Geometry truth is necessary but insufficient.

## Large-form priorities
1. Head must be subordinate to the shoulder/torso silhouette rather than dominate the body.
2. Face reads as forehead → orbital band → nose → mouth → jaw, not as independent marks on a surface.
3. Torso reads as ribcage → waist → pelvis with visible differentiation.
4. Arms taper through upper arm → elbow → forearm → wrist → hand.
5. Hair reads as crown + fringe + two side masses attached to scalp.
6. Garment reads as collar + torso panel + two sleeves.

## Detail discipline
No decorative surface noise before semantic readability passes. Use bounded cel bands and clean contours. Face and hair feature sizes are relative to the projected head rather than fixed screen pixels.

## Ground-truth boundary
The codebase supports a human-approved CharacterDesignTarget/Ground Truth state, but Phase 6.4 does not auto-approve one. `human_character_ground_truth=pending` until explicit user review.
