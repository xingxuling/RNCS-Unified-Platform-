## First Upgrade

This branch implements forty-one coupled high-leverage changes:

1. Deterministic environment mip chains with roughness-aware CPU sampling and WebGPU mip uploads/LOD sampling.
2. An executed HDR offscreen scene pass plus WebGPU tone-map pass, bound to the existing `tone-map` frame-plan stage.
3. glTF import hardening for normalized and sparse accessors, node matrices, and an explicit host image-decoder boundary.
4. GLB v2 JSON/BIN parsing with binary content sealed into the imported scene root, so a changed binary payload cannot reuse the prior asset identity.
5. A bounded WebGPU storage-light buffer for directional and point lights, including range attenuation and directional shadow visibility in the PBR fragment path.
6. An async glTF image path that extracts data-URI/GLB `bufferView` bytes, decodes browser PNG/JPEG/WebP through `createImageBitmap` and Canvas, and publishes the result as a VSR RGBA texture.
7. A rooted post-process contract for exposure, contrast, saturation, and vignette shared by the CPU reference renderer and the WebGPU tone-map pass.
8. A rooted HDR bloom contract with threshold, intensity, and radius controls shared by the CPU reference renderer and the WebGPU tone-map pass.
9. A sampleable depth32float scene target and rooted depth-of-field contract shared by the CPU reference renderer and the WebGPU tone-map pass.
10. A single glTF texture-source resolver that prioritizes `KHR_texture_basisu`, then `EXT_texture_webp`, then standard `source` for both synchronous import and asynchronous host decoding.
11. Rooted local environment probes with position/radius influence and diffuse/specular colors shared by the CPU PBR reference path and a WebGPU storage buffer.
12. glTF `KHR_materials_clearcoat`, `KHR_materials_ior`, and `KHR_materials_emissive_strength` scalar extensions mapped into the existing VSR PBR contract.
13. A bounded temporal-history contract: CPU reference blending, WebGPU `rgba16float` history/velocity copy/binding, explicit reset/resize invalidation, current/previous instance transforms, and temporal roots in frame evidence. This is bounded motion-vector reprojection, not a complete production TAA contract.
14. A bounded GPU texture residency contract: quality-tier byte budgets, per-texture byte accounting, last-use tracking, LRU eviction after submitted work, and upload/eviction counts in the WebGPU receipt.
15. A baked lightmap input and static bake contract: material/schema texture bindings, glTF `TEXCOORD_1` preservation, independent CPU/WebGPU UV selection, linear sampling, and rooted frame evidence; generated static triangle charts now duplicate eligible meshes, emit UV1 and a linear atlas, while production seam packing and dynamic GI remain outside.
16. A bounded GPU buffer residency contract: mesh, material, object, instance, deformation, and culling buffers share byte budgets, last-use tracking, post-submit LRU eviction, cache invalidation, and upload/eviction/resident-byte receipt evidence.
17. Executable alpha material behavior: CPU transparent packets sort back-to-front without depth writes, alpha-mask fragments discard before depth writes, and WebGPU uses a dedicated source-alpha blend pipeline while preserving the existing material/root contract.
18. Camera-motion temporal reprojection: history stores depth and the previous view-projection matrix, CPU resolves current pixels through current inverse projection into previous-frame UVs, and WebGPU binds the same current-inverse/previous-view-projection contract in the tone-map pass.
19. Depth-backed screen-space ambient occlusion: a bounded eight-tap contact-occlusion term is shared by CPU reference shading and the WebGPU tone-map path through the existing depth32float target; this is local screen-space shading, not full dynamic GI.
20. A native KTX2 container path for RGBA8 UNORM/SRGB mip levels, including host image-decoder routing without browser bitmap APIs; BasisU supercompression remains an explicit transcoder boundary.
21. A bounded TAA resolve contract: CPU and WebGPU history use projected previous depth for disocclusion rejection, and both clamp reprojected history against the current 3x3 neighborhood; the GPU path stores previous depth in a dedicated `r32float` history texture.
22. An authored convex-hull fixture path in RSR: finite non-coplanar vertices and triangle indices are validated at the authority boundary, rotated world-space support points reach GJK/EPA, and the same vertices and indices project into a VSR mesh with replay-root coverage.
23. An Entity Kernel binding path: `rncs.entity-state-batch.v0.1` rows are batch-root verified at the bridge, deterministically materialized as RSR authority bodies/fixtures, then projected through the existing RSR snapshot into tagged VSR scene nodes, verified frame plans and pixel roots; the Aether bridge has real Kernel-to-VSR and tamper-rejection integration tests.
24. A weighted-blended OIT path: transparent BLEND packets use rooted accumulation/revealage targets and a resolve composite in WebGPU, the CPU reference accumulates the same depth-weighted color and transmittance, and `transparencyMode:'sorted'` remains an explicit compatibility fallback.
25. A bounded screen-space dynamic indirect-light path: CPU reference and WebGPU tone-map execution share depth-backed color sampling with rooted intensity, radius, step, and thickness controls; `ssgiPasses` is emitted in the WebGPU receipt, while full DDGI/Lumen remains outside the contract.
26. A deterministic irradiance probe bake path: scene lights, environment, emissive geometry, probe layout, and generated colors are sealed into `vsr.spatial-irradiance-probe-bake.v0.1`; source/root verification applies the result to the existing CPU/WebGPU environment-probe storage path, while full DDGI remains outside the contract.
27. A deterministic static lightmap bake path: eligible static nodes are charted triangle-by-triangle into a bounded atlas, up to four fixed-point rays per chart sample opaque/masked static occluders, atlas padding is filled by deterministic texel dilation, and baked mesh/material records are sealed into `vsr.spatial-lightmap-bake.v0.2` for the existing CPU/WebGPU lightmap path.

A bounded persistent irradiance volume path: `vsr.spatial-irradiance-volume.v0.1` stores a budgeted 3D sample grid with source/topology roots, static visibility, CPU trilinear sampling, incremental light updates, WebGPU storage binding 8, JSON evidence, and real Chromium receipt coverage; full DDGI/Lumen remains outside.

A transactional Cell scene replacement path: `createRealityCellAssetSceneRuntime(...)` acquires the next binding before releasing the previous lease set, derives lifecycle roots, evicts receipt-owned old assets after the transition, and is exercised by a near -> far -> nearAgain real Chromium executor replay.
