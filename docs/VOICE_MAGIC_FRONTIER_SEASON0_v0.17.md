# 灰烬边境 Season 0：声控剑与魔法 RPG 垂直切片

## 产品命题

玩家以魔剑士进入灰烬边境，使用剑术承担稳定战斗，用声音或文字咏唱高价值魔法，并通过材料、魔导器和遗迹探索完成一条可持续扩张的版本世界主线。

## 核心闭环

```text
进入边境
→ 与莱拉学习第一句咏唱
→ 用火焰长枪完成野外试炼
→ 获得灰烬木、陨铁与符文尘
→ 在赤铁锻坊制造初阶魔导器
→ 解封遗迹
→ 击败三阶段熔心守卫
→ 登记下一版本区域“浮空学院”
```

## 声控结构

```text
麦克风输入
→ 浏览器 SpeechRecognition 转写
→ 本地标准化
→ 确定性词元匹配
→ 法术契约
→ 魔力/冷却/掌握状态校验
→ 权威战斗动作
```

当前语法不调用 LLM。语音识别不可用时，文字咏唱和数字快捷键提供等价入口。

## Season 0 内容

- 一块连续开放区域：灰烬边堡、风蚀草原、灰烬林地、封锁遗迹。
- 4 名主要 NPC 和 3 名共享世界幽灵投影。
- 灰烬小鬼、苔原猎狼、遗迹哨兵、熔心守卫。
- 火焰长枪、寒霜护壁、雷霆锁链、风行步、治愈之光、余烬新星。
- 剑击、攻击收招、生命/魔力/体力、等级成长、掉落、药剂、魔导器制造。
- 本地权威存档、历史事件、状态根与版本地图门。

## 美术生产

本版建立一张可执行风格图集，包含玩家、NPC、怪物、首领、建筑、地形和法术图标。它用于验证资产族、轮廓语言和游戏内嵌入，不代表最终商业 MMO 美术质量。

后续资产升级顺序：

1. 角色方向与动作帧扩展；
2. 模块化装备与职业外观；
3. 怪物动作、受击和阶段形态；
4. 法术粒子组件与元素材质；
5. 地形、建筑和地下城模块化套件；
6. 转入 GPU VSR 或外部 3D Provider。

## 版本世界

Season 0 击败首领后只建立下一版本的权威记录，不开放伪地图。后续可按版本增加：

- Season 1：浮空学院；
- Season 2：深海王庭；
- Season 3：失落龙脉；
- Season 4：群星裂隙。

每个版本增加一个区域资产族、一条主线、一个法术词元族、一个首领和一组多人事件。
