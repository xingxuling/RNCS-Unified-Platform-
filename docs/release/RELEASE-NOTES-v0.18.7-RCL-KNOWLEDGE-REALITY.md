# RNCS + Aetherworld Unified v0.18.7-alpha.1

## Release focus

RCL v0.3 adds Knowledge Reality and completes the first executable small-data AI loop across RNCS reality domains.

## Added

- ninth first-class domain: Knowledge Reality;
- typed `Know<T>` claims with confidence, evidence, source, scope and dependencies;
- claim formation, inference, reinforcement, contradiction, revision and forgetting;
- Inner Reality as a composite plane of perception, neural state, living state and knowledge;
- Execution Reality as a composite plane of projections, realized transitions, authority, host receipts and evidence;
- `small-data-agent.rcl`, demonstrating sensor-to-knowledge-to-action without an LLM in the control loop;
- 22 passing RCL tests.

## Strategic correction

This release does not claim zero-data intelligence. Rules, ontologies and world models are prior information. The value is that structured domains can use small observations and execution feedback instead of requiring a large pretrained model to contain the whole policy and world model.

## Boundary

Natural-language understanding, raw multimodal perception, automatic ontology discovery, probabilistic inference, continuous online learning, native VM and self-hosting remain future work or replaceable providers.
