# RNCS + Aetherworld Unified v0.18.5-alpha.1 — RCL v0.1

## Release focus

This release adds the first executable Reality Computation Language kernel to the unified mother engineering project.

## Added

- `packages/languages/reality-computation-language`
- independent RCL lexer, parser, AST, type checker and IR compiler;
- runtime for candidate foresight and authoritative realization;
- first-class subjects, warrants, emergence and resonance;
- pure recursive reckoning for general computation;
- simultaneous typed reality alteration;
- host seams for computer reality and receipt capture;
- transition roots, witnesses and RNCS proposal bridge;
- 12 behavioral tests and three executable examples;
- root commands `test:rcl` and `demo:rcl`;
- RCL registration in `rncs.modules.json`.

## Semantic boundary

RCL does not replace MSL or CSL:

- MSL interprets mother sequences;
- CSL compiles concepts and ontological structures;
- RCL computes and realizes authorized changes across shared, subject and computer realities.

## Known limits

RCL v0.1 is bootstrapped on Node.js, has no native bytecode VM, no distributed commit protocol and no external-effect compensation protocol. These are planned language/runtime upgrades rather than hidden claims of completion.
