# RNCS＋Aetherworld Unified v0.18.8-alpha.1

## RCL v0.4：自然语言、理解与创造现实运行平面

本版保持 RCL 九个一级现实域不变，新增三个复合认知运行平面：

- Natural Language Reality：把话语解释为带证据、槽位和置信度的候选意图；
- Understanding Reality：把意图、知识和观测组织为可检验、可反驳的世界解释；
- Creative Reality：产生多个受约束候选，按效用、可行性、新颖度和风险评分选优。

完整链路：

```text
话语 → 候选意图 → 可解释理解 → 多候选创造
→ 权界裁决 → 候选现实 → 正式执行 → 新证据
```

## 验收

```text
RCL 专项：28/28 通过
母工程 RCL 集成：28/28 通过
RNCS 动态运行时：healthy
RCL 注册版本：0.4.0-alpha.1
```

端到端示例将中文请求“请打开温室灯”解释为 `activate` 意图，结合安全知识形成理解，比较执行与澄清方案，选出评分 `0.881` 的执行候选；该候选取得 `greenhouse.control` 权限后，才把 `greenhouse.light` 改为 `true`。

## 边界

- 自然语言平面当前是显式规则和类型化解释器，不是通用大语言模型；
- 理解平面形成可证伪模型，不宣称已解决开放世界常识；
- 创造平面是受约束候选生成和选择，不等同于大规模生成模型；
- 三个平面均不能绕过权界现实直接执行外部动作。
