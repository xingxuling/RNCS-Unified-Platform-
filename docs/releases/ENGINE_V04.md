# RNCS Engine v0.4

RSR 0.6.0-alpha.1 adds rotated fixture offsets, OBB world bounds, sphere-to-OBB contact and 15-axis OBB SAT collision.

VSR 0.5.0-alpha.1 replaces the reference lighting approximation with Cook-Torrance GGX in both CPU reference rendering and WebGPU WGSL, including metallic energy conservation, Fresnel, Smith masking, clearcoat, material AO and IOR.

Validation: RSR 164/164, VSR 159/159, Reality Studio 188/188, Reality Build 113/113, Gateway 10/10, unified integration 11/11, and 12/12 runtime health.
