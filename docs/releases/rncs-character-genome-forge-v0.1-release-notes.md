# RNCS Character Genome Forge v0.1 Release Notes

Released as an alpha reference foundation on 2026-08-06.

## Added

- RNCS Character Genome IR with four authority layers and a semantic morph
  constraint graph.
- Deterministic Character Phenotype Compiler with modular GLB assets, three
  LODs, rig, morphs, expressions, visemes and cross-media projections.
- Explicit RAGF Character Genome Reference Provider plus VSR and RSR character
  profiles.
- Character RCL dialect, compiler bridge, CLI, impact analysis, replay,
  rollback and approval-gated commit.
- Reality Studio Character Genome Forge with generated mesh preview, editing,
  locks, random candidates, undo/redo, snapshot/compare, export and Anime bind.
- Lan Tianlin reference asset family and `何罪之有` Cut evidence.
- Focused positive and negative suites, local rebuild benchmark, Evidence
  Ledger and hash-manifested source ZIP.

## Compatibility

Existing RAGF, VSR, RSR and Anime contracts are extended additively. The generic
RAGF character generator remains available and is not silently replaced.

## Known limits

The included Provider is offline procedural reference code. Commercial art
quality, external DCC/provider parity, production hair and cloth simulation,
target GPU/device validation and human acceptance are outside this release
claim.
