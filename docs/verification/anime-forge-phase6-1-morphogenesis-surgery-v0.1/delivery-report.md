# RNCS Anime Forge v0.1 Phase 6.1

## Delivery Boundary

Phase 6.1 adds a fresh RNCS-native deterministic CPU morphogenesis runtime on
the actual `main-95` baseline. It compiles one Character Genome into Body
Surface 2.0, Face Rig 2.0, Hair Topology 2.0, Shoulder/Torso/Pelvis, Joint
Deformation and Hand Abstraction contracts, then renders a shared anatomy
validation pack and a 120-frame native shot.

The authority boundary remains: Episode is authoritative, Cut is derived, Clip
is reusable, Patch is local, and Continuity is global. The Reality Studio
workspace is evidence-first and read-only for frame, A/B, repair and rollback
preview operations.

## Federation And Evidence

The required review order and residual audit are recorded in
`federation-review.md`. The implementation records genome, visual genome,
surface, face, hair, joint, hand, provider, frame, repair, media and ledger
roots. `file-hash-manifest.json` records artifact SHA-256 values. The ledger
distinguishes internal roots, ledger-file hash basis, evidence bundle root and
media/source hashes.

## Current Status

- Body Surface, Face Rig, Hair Topology, torso/pelvis, joint and hand contracts: implemented and schema-tested.
- Anatomy Validation Pack: ten views from one genome and one morphogenesis system.
- Secondary motion: hair lag, breathing, costume lag and overshoot are present in Pose IR and frame manifest.
- Native shot: 120 frames at 1280x720 and 24 fps are rendered by the deterministic CPU provider.
- WAV: generated by the real deterministic audio path.
- MP4: requires the real FFmpeg and ffprobe executables; missing tools fail closed and never create a fake MP4.
- Human visual acceptance: pending.
- Commercial animation quality: not proven.

## Verification Commands

```text
npm test --workspace @taowind/native-character-morphogenesis-runtime
node --test apps/reality-studio/tests/native-character-surgery.test.mjs
npm run build:anime-phase6-1-morphogenesis
npm run verify:anime-phase6-1-morphogenesis
npm run package:anime-phase6-1-morphogenesis
```

CI installs FFmpeg and ffprobe before running the build. A local machine that
lacks either executable must report `MEDIA_TOOL_NOT_FOUND` and remains blocked
at the final media gate.
