This record is an internal engineering review using the requested civilization lenses. It does not claim that external people or organizations were consulted.

## Founder Twin

The actual problem is not that Phase 6.2 needs more contour polish. The authority chain is still incomplete. A character can only be certified after geometry, topology, attachment, visibility, and measurement exist before stylization. Phase 6.3 therefore upgrades the existing canonical morphology compiler instead of adding a second morphology compiler.

## 柳清莲 Gate

The visual rejection is treated as a durable safety gate. The supplied Phase 6.2 frame is retained as a regression fixture and must remain visibly and numerically rejected until a new implementation proves the required relations. A green JSON boolean without measurement is not acceptance.

## 洞哥 Grounding

Facts observed in the baseline:

1. `canonical-morphology.mjs` computes numeric dimensions and retains primitive volume descriptors, but does not expose a continuous field or a canonical triangle surface.
2. `deformation.mjs` still emits contour primitives and point-like face/scalp anchors.
3. `projection.mjs` projects those primitives but does not produce a depth or visibility buffer.
4. `renderer.mjs` rasterizes polygons, lines, and ellipses and reports `anatomy_authority: false`.
5. The Phase 6.2 certificate is mostly structural booleans and accepts `self_intersection_valid` and `silhouette_connected` without measured evidence.
6. The Phase 6.2 review remains `candidate-pending-human-review`.

The supplied rejection fixture is therefore a valid RED input, not a visual score. It shows a large detached head, block-like torso, and primitive-like neck, face, hair, and limb transitions. The post-Phase-6.2 contact sheet is better than the supplied fixture but remains experimental 2.5D and pending human review.

## Product civilization

The product contract is an inspectable character production kernel. The first screen and build output must answer whether geometry is valid, whether visibility is valid, and whether media is reproducible. A styled frame is a consequence of those answers, not the authority.

## UX and design civilization

Reality Studio must present geometric truth progressively: gate status, measured ratios, connected components, depth/occlusion diagnostics, and the exact evidence root. It must retain the Phase 6.2 Cut browsing and repair workflows. Cut is derived and must not become a second authoring authority.

## Animation director civilization

The pipeline preserves Episode authority, derives Cuts and Clips, and applies local patches only after the episode-level morphology and pose contract is compiled. Camera and stylization can change the read, but cannot repair a disconnected body.

## Character performance civilization

Identity comes from the Character Genome and canonical morphology root. Face features, hair roots, garment panels, and pose are attached to surfaces or bones. A mouth change must not move the skull, and a camera change must not change body dimensions.

## Technical art civilization

The field must expose semantic regions, blend groups, material regions, and deformation policy. Mesh extraction is deterministic and retains topology and ancestry. Hair and clothing receive clearance and penetration checks rather than being scaled copies of a torso contour.

## Graphics and compositing civilization

The visibility kernel owns depth ordering, clipping, backface handling, surface IDs, region IDs, and normal/depth diagnostics. Anime line and fill styling runs after camera visibility. `cos(head_yaw)` remains only a style hint and cannot stand in for depth.

## Sound civilization

Phase 6.3 does not change the Voice Forge or Audio Forge authority. A later five-second media slice may consume the existing episode-level audio contract, but it cannot bypass geometry gates to produce a misleading acceptance artifact.

## Engineering civilization

Compatibility is preserved for `compileMorphology(genome, profile)`. The old contour renderer remains available only as a legacy/regression path. No new parallel morphology authority is allowed. The implementation is split into small commits and each slice has a RED, implementation, GREEN or explicit blocked evidence gate.

## Code civilization

The selected foundation is a deterministic CPU implicit field compiled by the existing canonical morphology compiler and extracted to a canonical surface mesh. Surface skinning, attachments, visibility, and style consume the compiler result. Every certificate gate stores measurement, allowed range or rule, method, evidence root, and pass.

## Test civilization

The old Phase 6.2 regression suite stays intact. New tests must first prove the old contour output is RED on measured geometric truth, then prove law enforcement, field continuity, mesh topology, attachments, visibility, projection, and evidence reproducibility. Property fuzz remains `1000 genomes x 3 poses x 3 camera views = 9000 cases` and may use a bounded low-resolution mesh mode for performance.

## Security civilization

Provider and media evidence are untrusted until hashes, inputs, and tool versions are recorded. Missing FFmpeg is a failure, not a successful placeholder. Human ground truth stays `pending` without an approved pack.

## Release civilization

The release must distinguish editor/kernel completion, native geometry completion, real media completion, experimental visual quality, human acceptance, and commercial parity. A static-gate failure produces a foundation package and failure report, not a fake five-second success.

## Integration Court decision

**Decision: revision requested; implementation may proceed only through measured RED.**

Required order:

1. Measure and archive the Phase 6.2 contour output against the named geometric truth metrics.
2. Keep the RED fixture and human rejection report.
3. Enforce law constraints in the existing canonical compiler.
4. Add the field, canonical mesh, skinning, attachment, visibility, grammar, and evidence contracts in that order.
5. Run the static three-view gates before any episode media build.

## Evidence Ledger entry

This review is evidence for the baseline and decision only. It is not evidence that Phase 6.3 is complete. The phase ledger must later include:

- `phase6-2-failure-measurements.json`
- `phase6-3-after-measurements.json`

## Unprovable claims and rollback

The following remain unprovable at this stage: professional animation quality, commercial production parity, human approval, external provider quality, and clean-machine GPU performance. If a gate regresses, revert only the Phase 6.3 commits or disable the Phase 6.3 compiler profile. Phase 6.2 APIs and evidence remain intact.
