# URRF large-world Power Plane evidence

This slice closes the v0.3 Power Plane to Representation Portfolio seam:

`PowerProfile + ResourceBudget + VisualDemands → LoadSheddingPlan →
chunk-bound decisions → URRF PROXY minimum-reality selection → VSR frame`

The Resource Governor remains an RNCS candidate plan. Active chunks bind only
to explicit visual/refinement/minimum-reality candidate IDs; pressure actions
are visible on every selection row, and unbound chunks are reported instead of
being silently treated as governed. The lowering does not mutate world truth,
perform provider offload, or implement frequency control.
