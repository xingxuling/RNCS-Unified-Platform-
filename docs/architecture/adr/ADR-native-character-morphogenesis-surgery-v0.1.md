# ADR: Native Character Morphogenesis Surgery v0.1

- Status: accepted for Phase 6.1 implementation
- Baseline: `main-95@4d42442855a371903563f644b0f24ee9a9defc4d`
- Scope: Character Body Surface 2.0, Face Rig 2.0, Hair Topology 2.0, joint deformation and deterministic validation media.

## Decision

Implement a fresh RNCS-native deterministic CPU morphogenesis runtime on top of the actual `main-95` baseline. The runtime will compile one Character Genome into explicit identity, surface, face, hair, joint and hand contracts, then project canonical anatomy through camera/head orientation before applying style simplification.

The runtime will not cherry-pick the unmerged Phase 6 PR. The PR #60 evidence is an audit baseline only. The implementation may preserve the same authority principles and media contracts, but every Phase 6.1 root and output is generated by this branch.

## Consequences

- The branch contains a complete, independently reproducible surgery foundation instead of an implicit dependency on an unmerged branch.
- The validation pack becomes the first acceptance artifact; the rebuilt five-second shot is the second.
- The renderer remains experimental 2D/2.5D and CPU-bound. Human visual acceptance stays separate.
- Future integration with Phase 6 or a later merged native kernel must be handled as an explicit compatibility or rebase decision.
