# 联合升级协议 v0.1

1. 修改模块后运行 `npm run impact -- <changed paths...>`。
2. `test:affected`根据依赖图测试直接模块及所有下游模块。
3. Gateway运行时清单是运行边界，模块不得复制其他模块源码。
4. `rncs.modules.json`记录统一版本与每个内部模块版本。
5. 只有受影响模块需要改内部版本；母工程在联合发布时改suiteVersion。
6. AutoRAG项目索引放在`artifacts/project-index.json`，不把缓存写回源码目录。
7. AetherFusion迁移必须落到模块注册表中的路径，并在融合后运行影响测试。
