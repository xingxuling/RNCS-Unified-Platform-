# 多情景仿真协议 v0.2

RBF不会用一个单一数字假装未来确定，而是让每个候选分支至少经过：

- 基准情景；
- 不利情景；
- 有利情景。

每个情景都有整数基点概率，合计必须为10000。每个情景分别输出收益、成本、风险、置信度、持续时间以及硬约束违规。

聚合层输出：

- 概率加权预期指标；
- 最坏情景指标；
- 韧性分数；
- 是否所有情景都满足硬约束。

## 外部仿真器

`simulateBranch`允许传入统一Adapter或按情景Adapter。RSR物理模拟、组织项目模拟、成本模型或行业专用仿真器都可以作为Provider返回整数指标。

RBF只绑定输入、输出和证据根，不声称内置模型能够预测真实社会或商业未来。
