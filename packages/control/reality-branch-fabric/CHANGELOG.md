# Changelog

## 0.2.0-alpha.1

- 候选分支从扁平列表升级为可继承的现实分支树。
- 新增基准、不利、有利情景与概率加权聚合。
- 新增最坏情景、韧性指标、四类权重敏感性和推荐稳定度。
- 新增分支写入冲突矩阵与主现实漂移检测。
- 新增沙箱执行计划、逐步状态根、Provider证据与逆操作。
- 新增Provider外部回滚；缺少回滚时标记`rollback_incomplete`。
- 新增执行收据绑定的合并提案。
- 新增权威请求、批准/拒绝决定与过期检查。
- 新增RNCS Transition v0.2、RFE提交收据与Reality Studio投影。
- 新增重基线协议、CLI命令、九份JSON Schema与离线工作台。
