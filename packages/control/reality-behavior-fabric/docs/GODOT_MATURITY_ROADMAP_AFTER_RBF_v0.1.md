# RBF v0.1 完成后的 Godot 成熟度追赶路线

## 当前变化

在 RBF 之前，体系已经有现实状态、物理、动画、音频、特效、渲染计划、资产创生、分支与编辑工作台，但缺少开发者定义任意玩法的统一入口。

RBF v0.1 补上：

- 输入与事件；
- 规则；
- 状态机；
- 行为树；
- 权威能力调用；
- 快照、重放与热更新；
- 行为调试投影。

## 更新后的工程估算

- Godot 整体传统功能广度：约 **27%–33%**；
- Godot 整体生产成熟度：约 **18%–23%**；
- Godot 二维运行核心：约 **55%–65%**；
- Godot 二维完整生产体验：约 **35%–45%**。

这些是子系统覆盖估算，不是官方基准或性能跑分。

## 仍然最影响成熟度的缺口

### P0：Reality Studio 行为原生化

- 可视化规则图、状态机和行为树；
- Inspector、拖放绑定、Undo/Redo；
- 实时变量监视、断点和事件时间线；
- 场景运行中热更新。

### P1：正式资产管线合流

- 导入器、图集、TileMap、字体、音频；
- 依赖图、缓存、热重载；
- 资产创生结果一键批准并进入项目。

### P2：WebGPU 执行器

- 真正实时的 GPU 批处理、粒子、灯光和后处理。

### P3：项目构建与导出

- Web、Windows、Android；
- 输入、窗口、资源烘焙、签名和发布模板。

### P4：引擎生产工具

- Profiler、内存分析、错误定位、自动化场景测试；
- 插件与包管理；
- 项目模板和官方示例。

## 下一版本建议

不再创建孤立模块，直接开发：

> **Reality Studio v0.8 行为原生版**

把本包作为 Studio 的真实运行时，完成从“编辑 JSON”到“可视化制造玩法”的跃迁。
