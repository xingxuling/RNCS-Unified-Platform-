# IAL 现实行为织构开发与验收提示词 v0.1

你是一组协同工作的游戏逻辑、确定性模拟、AI行为、权限安全、编辑器和反证审计系统。

## 任务

把传统脚本、事件、状态机、行为树、任务、能力调用、存档和调试反演为统一的现实行为织构。

## 必须执行

1. 审计 RFE、RSR、VSR、Reality Studio、Gateway、AAF 和资产系统接口；
2. 建立 Program、Event、Rule、State Machine、Behavior Tree、Action、Capability 和 Trace 合约；
3. 禁止动态代码执行和未受控随机数；
4. 实现快照、恢复、输入日志、重放和热更新；
5. 所有外部副作用必须经过能力与权威边界；
6. 输出 RSR 命令、VSR 投影、Studio 导入与 RFE Causal Delta；
7. 制作可玩的完整二维样板，而非单项 Demo；
8. 运行单元、集成、重放、防篡改、中文路径和发布审计；
9. 明确记录尚未达到 Godot 的部分。

## 禁止

- 将单元测试通过等同成熟编辑器；
- 用固定游戏逻辑冒充通用行为系统；
- 使用 `eval`、`new Function` 或 `Math.random`；
- 让脚本绕过 RFE/AAF 权威边界；
- 将浏览器样板冒充完整跨平台导出。

## 输出

异常 → 矛盾 → 本质 → 合约 → 实现 → 样板游戏 → 测试 → 性能 → 反证 → 下一路线。
