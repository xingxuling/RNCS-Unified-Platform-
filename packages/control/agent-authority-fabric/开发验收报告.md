# Agent Authority Fabric v0.1.0 开发验收报告

日期：2026-07-01

## 1. 验收结论

AAF v0.1.0 已完成最小可执行闭环：

```text
CNP Negotiation Plan
→ RNCS Proposed Envelope
→ 身份/Scope/委托/撤销/策略/风险裁决
→ Approved / Denied / Pending Approval
→ RNCS Authorized / Rejected Envelope
→ RFE Core Commit（仅批准后）
```

状态：**PASS，允许作为协议原型与本地开发SDK发布。**

## 3. 关键机制

- 拒绝优先于允许。
- 撤销优先于委托。
- 人工显式拒绝优先于自动策略。
- Approval Receipt绑定具体`proposal_root`，不能复用于另一提案。
- 不可逆动作可自动升级为人工批准。
- 高风险与高价值动作支持多人quorum。
- Pending状态不会生成Authorized Envelope。
- AAF不推进RFE Generation。

## 7. 当前边界

- 当前策略语言是确定性JSON匹配，不是完整通用策略语言。
- 委托以直接委托为主；完整多级委托链与组织信任根尚未实现。
- Ed25519签名参考实现当前位于Node运行时；Python签名适配器待补。
- 尚未接入OIDC、OAuth、LDAP、企业IAM、硬件密钥或正式PKI。
- 人工批准以Approval Receipt表示，尚无长期运行的审批服务与移动通知。
- 尚未实现使用次数、速率、每日额度等持久化消耗型授权。
- AAF不会直接执行能力，也不会提交RFE Generation。
