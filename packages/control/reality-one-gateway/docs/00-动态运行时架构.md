# 动态运行时架构

## v0.2问题

v0.2通过复制ICAR、LAR、RFE和HNAC源码形成组合入口。优点是容易演示，缺点是：版本固化、修复无法独立升级、同一模块存在多份事实源、网关承担领域逻辑。

## v0.3边界

Gateway只拥有：

1. 运行时发现；
2. Manifest与版本协商；
3. 依赖图；
4. 传输；
5. Bridge；
6. 调用回执、超时和幂等；
7. 跨运行时编排。

运行时仍拥有自己的对象、协议、测试和发布包。

## 传输

- `node-module`：动态导入独立npm包。
- `stdio`：向外部进程发送单行JSON请求并接收单行JSON结果。
- `http`：保留给下一版本。
