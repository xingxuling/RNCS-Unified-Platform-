# Reality One v0.2 → v0.3

| v0.2 | v0.3 |
|---|---|
| `core/icar/*` | `@taowind/icar-native-envelope-runtime` |
| `core/vendor/rfe/*` | `@taowind/rfe-core-sdk` |
| `core/vendor/lar/*` | `@taowind/living-artifact-format` |
| 网关内写死权限 | `@taowind/agent-authority-fabric` |
| 网关内写死能力选择 | `@taowind/capability-negotiation-protocol` |
| 固定模块列表 | `runtimes/*.runtime.json` |
| 源码直接调用 | 统一Bridge与Invocation Receipt |

v0.3仍可保留v0.2生成的LAF对象作为输入，但不会加载v0.2内嵌运行时。
