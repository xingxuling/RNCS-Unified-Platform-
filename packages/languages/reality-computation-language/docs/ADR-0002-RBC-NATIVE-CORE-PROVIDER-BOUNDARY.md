# ADR-0002：RBC 原生核心与十四域 Provider 边界

## 状态

Accepted — 2026-07-04

## 决策

RCL 原生 VM 首先只承担跨域不变量：状态、事务、权界、边界、证据和 reality root。物理、神经、生命、科学等专业现实继续作为 Provider 或参考运行时模块接入。

## 原因

一次性把十四域全部重写到 C 会制造两套不一致实现，并把“原生化”误当成功能完成。最小原生核心可以先通过 parity 固定语义，再逐域迁移 Provider。

## 后果

- 原生字节码编译器对未支持域明确报错；
- 不允许静默退回 Node.js 后仍声称原生执行；
- 参考运行时继续作为语义权威和迁移对照；
- 每个后续原生域必须提供 parity 与反证测试。
