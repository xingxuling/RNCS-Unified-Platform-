# RCL v0.12 嵌入式 VM 开发验收报告

## 版本

- RCL：`0.12.0-alpha.1`
- Native VM：`0.6.0-alpha.1`
- RBC：`1.1`

## 完成内容

1. 将 VM 核心拆分为可嵌入实例生命周期；
2. 输出静态库、共享库与公开 C 头文件；
3. 实现加载一次、同进程重复执行；
4. 实现长驻 `rclvmd`；
5. 新增 Provider ABI v1 与 `CALL_PROVIDER`；
6. 新增 Node 长驻管理器；
7. 保留 Stage-5 自托管 RBC 编码器；
8. 建立 AOT 热执行与直接嵌入基准。

## 功能证据

- `provider_demo` 通过 `echo.text` 返回结构化 JSON；
- 长驻示例首次执行约 1.03 ms，后续约 0.19–0.31 ms；
- 同一 RBC 重复执行保持相同状态与 source root；
- 未注册/不支持 Provider 会明确失败。

## 裁决

本版达成“原生 VM 可作为 RNCS 内嵌运行时”的验收线，并证明 VM 本体不再受进程启动瓶颈支配。尚未达成生产级多线程、异步 Provider、平台沙箱和完整自托管编译器验收线。
