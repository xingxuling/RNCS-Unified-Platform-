# RNCS Character Genome Runtime v0.1

This package defines the RNCS-owned identity contract for parameterized digital actors. It separates immutable identity and morphology from appearance loadouts and transient state overlays.

The included provider catalog is deterministic, offline and Apache-2.0 licensed. It is a reference implementation, not a commercial character-art provider. Generated assets must pass the downstream Character Phenotype Compiler quality and continuity gates before an RNCS authority commit can be requested.

Run `npm test --workspace @taowind/character-genome-runtime`.
