# VSR v0.4 命名边界反演：渲染器 → 空间现实执行器

## 旧边界

传统渲染器把任务定义为“把三角形画到屏幕”。

## 被遗漏的问题

神经接口虚拟世界需要的不只是三角形，而是：

- 哪个世界正在被观察；
- 观察者站在哪里；
- 物体在三维空间中如何连续存在；
- 哪些视觉差异只是设备预算差异；
- 哪些结果需要证据、重放和跨设备等价；
- 后续触觉、听觉和神经投影如何引用同一个空间事件。

## 新边界

> VSR 不只输出像素，而是把权威世界、观察者位置和设备能力编译为可执行、可验证的空间体验计划。

## v0.4 验证范围

本版先建立最小三维器官：Mesh、Camera、Depth、Material、Light、Shadow、LOD、GPU计划和确定性参考图。

它没有宣称完成：

- 完整 glTF / FBX 导入；
- 纹理与法线贴图；
- IBL、SSR、TAA、GI；
- 蒙皮、Morph、毛发、布料；
- 大世界流送；
- XR 双目和空间追踪；
- 真实显卡性能验收。
