# 资产生成命名边界反演

## 异常

现有 AI 资产生成通常结束于一个文件。文件可能漂亮，却没有稳定身份、世界关系、行为接口、平台预算和可追溯来源。

## 旧边界

```text
提示词 → 模型 → 文件
```

## 反演

```text
世界缺口
→ 主体意图
→ 资产基因组
→ 能力协商
→ 多候选现实
→ 自动验收
→ 权威批准
→ 持续资产
```

资产不再等于字节文件，而是一个持续存在的现实对象。图片、精灵、声音、粒子、碰撞体和未来 3D 模型都是该对象的不同组成或投影。

## 生活例子

传统生成像“画了一张新员工照片”；现实资产创生则同时建立员工身份、岗位、技能、制服规格、设备权限和档案。照片只是其中一项。

## v0.1 反证边界

- 内置生成质量只能证明协议，不代表通用内容质量。
- 自动评分只能检查明确规则，不等于替代艺术总监。
- 外部模型可能不可复现，因此 Provider Evidence 必须记录模型与请求。
- 资产进入权威现实前仍需审批。
