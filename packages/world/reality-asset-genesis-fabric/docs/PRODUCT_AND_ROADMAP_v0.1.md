# 产品与路线

## v0.1：二维结构闭环

概念 SVG、精灵 PNG、WAV、粒子、碰撞、候选、验收和持续包。

## v0.2：真实生成模型与二维生产

- 图像模型 Provider
- 多视图一致性
- 自动抠图、切图和图集
- Tile、UI、场景背景
- 许可证与来源策略
- Studio 内候选比较与局部重生

## v0.3：3D 资产创生

- glTF / GLB
- 拓扑和法线验收
- UV 与纹理组
- 骨骼、权重和动画
- LOD、碰撞代理与移动端变体

## v0.4：世界级程序生成

- 地形、建筑、植被和关卡语法
- 资产家族和生态规则
- RSR 运行验收
- VSR 画面验收

## v1.0：现实资产创生平台

资产从意图出生，并在不同模型、工具、设备和世界版本中保持身份连续性。
