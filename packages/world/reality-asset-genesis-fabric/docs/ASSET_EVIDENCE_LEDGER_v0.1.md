# Asset Evidence Ledger v0.1

The ledger binds:

Asset Intent, Asset Genome, ALWR Asset Requirement, Provider Manifest, Job Lifecycle, Provider Result, Candidate, Production Court, and optional World Placement.

The ledger keeps the following distinction explicit:

- provider runtime execution;
- provider result normalization;
- candidate validation;
- production court decision;
- living asset family candidate;
- RNCS commit request;
- authoritative world mutation.

The first five stages can be executed by an external organ. The final authority remains outside the provider.
