# Reality Asset Genesis Fabric v0.5.0-alpha.1

## Social Ecology & Technology Genesis

新增：

- 无LLM确定性社会生态生成；
- 2.5D等距世界种子；
- 代表性居民、家庭、机构、派系和社会关系；
- 连续历史模拟和可验证事件根；
- 技术概念六维组合语法；
- 技术前置知识、可证伪实验、原型、工程工作包、制造与扩散路径；
- 玩家政策、投资、组织和技术提案介入；
- 历史分支和确定性重放；
- 交互式离线预览；
- CLI：`generate-society`、`verify-society`、`inspect-society`；
- 20项社会创生专项测试。

边界：生成的未来技术属于模拟假说，必须经过现实科研和工程验证。
