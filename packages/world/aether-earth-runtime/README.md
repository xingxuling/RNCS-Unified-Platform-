# Aether Earth Runtime v0.1.0-alpha.1

A deterministic RNCS world runtime that combines:

- a 16×16 multi-climate Earth sandbox;
- 100 persistent small-data organisms;
- 512+ executable, evidence-bearing RCLpedia claims;
- 1×, 10× and 100× logical spacetime;
- reversible world capsules and compressed history;
- collective-intelligence crystallization into runnable RCL/RBC artifacts;
- a browser projection and an Android foreground/background host source project.

## Run

```bash
npm test
npm run demo
npm run benchmark -- 1000
npm run build:web
npm run verify
```

## Authority boundary

A generated crystal is always a candidate. It is compiled to RBC and executed in an isolated native RCL VM before it can be promoted into the sandbox strategy list. The prototype does not grant generated code arbitrary Provider access.
