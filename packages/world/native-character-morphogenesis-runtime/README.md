# Native Character Morphogenesis Runtime

Phase 6.1 deterministic CPU runtime for the RNCS Anime Forge character surgery gate.

The runtime keeps Character Genome identity authoritative, then compiles explicit
Body Surface, Face Rig, Hair Topology, Shoulder/Torso/Pelvis, Joint Deformation and
Hand Abstraction contracts. Canonical anatomy is projected through camera and head
orientation before anime style simplification.

This is an experimental 2D/2.5D implementation. It is not a claim of commercial
animation quality or full 3D skinning parity.

The package exposes `buildPhase61Evidence()` and a CLI for the ten-view Anatomy
Validation Pack, the 120-frame native shot, deterministic WAV, real FFmpeg/ffprobe
MP4 closure, local repair A/B evidence and Evidence Ledger. A missing media tool
is a hard failure and never becomes a synthetic MP4.
