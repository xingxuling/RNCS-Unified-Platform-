# Changelog

## Unreleased

- Added candidate-only `rncs.large-world-stream-transition.v0.1` receipts to the existing `observe()` owner. Each stream now binds the previous stream root, previous/next active IDs, entered/retained/released IDs, and budget-evicted IDs under a separately verifiable transition root; this is a source residency receipt, not an automatic scheduler or canonical world mutation.
- Added the candidate-only URRF nine-family golden-set contract and executor. The Forge now has a machine-readable `POSITIVE`/`BOUNDARY`/`OPEN_DOMAIN_NEGATIVE` catalog for all nine asset families, runs 18 bounded reference cases plus nine same-seed replays, checks profile-specific mesh/VFX structure, and requires exact fail-closed rejection for unregistered open-domain inputs. Contract/evidence schemas and the root integration are persisted; the result is local candidate closure, not external AI generation or AAA release proof.
- Added `MultiProcessReplicationHarness`, `LargeWorldProcessNode`, and `rncs.large-world-multi-process-evidence.v0.1`. Three real child processes now exercise snapshot/delta replication, lease epoch/fencing admission, cache invalidation, failover migration, durable hydration, source-process failure, and stale-writer rejection. The process harness is local candidate evidence only; it does not claim distributed consensus, production network security, or canonical ownership outside RNCS.
- Expanded the built-in URRF reference route to execute deterministic RAGF candidates for `vehicle`, `structure`, `environment`, `vegetation`, and `resource` in addition to `character`, `creature`, and `prop`; static families use profile-specific geometry and no fake rig/animation output. `vfx` executes a dedicated particle/volume/flipbook/curve reference route with no mesh shortcut. AAA acceptance gates remain blocked without independent proof.
- Added candidate-only VSR payload materialization for Universal Art Asset Assembly: selected GLBs and external Base Color/Normal/ORM/Emissive PNGs now form a dependency-complete catalog, are read with byte-length/SHA-256/file-root checks, and stream through VSR's dependency closure. The integration imports the actual PNG bytes through the new external-PBR adapter, compiles verified local CPU frames, and produces decoded CPU reference-raster PNG pixel evidence; GPU, target-device, production delivery, and AAA quality remain separate gates.
- Added candidate-only Universal Art Asset Assembly and VSR projection contracts: materialized GLB/PBR bytes are rehashed and bound to batch roots, selected LODs, integer-millimeter placements, cells, and a cross-asset artifact index; the VSR lowering remains an import/streaming reference seam and does not write RNCS truth or prove AAA quality.
- Added candidate-only `urrf.universal-art-asset-evidence-bundle.v0.1` and `createUniversalArtAssetEvidenceBundle` / `verifyUniversalArtAssetEvidenceBundle`. Provenance/license, art-direction, quality, and human-art receipts can now travel as one rooted, coverage-checked envelope and feed the existing acceptance evaluator only after every nested receipt independently verifies against the exact Genome, Candidate, local inspection, and artifact roots. Missing or tampered receipts remain `INCOMPLETE`/`BLOCKED`; the bundle grants no Provider, human, commit, or RNCS authority.
- Added candidate-only `generateUniversalArtAssetBatch` / `verifyUniversalArtAssetBatch` and `universal-art-asset-batch.v0.1`. Up to 64 requests now produce isolated numbered Forge workspaces, per-asset summaries, a cross-asset artifact-root index, and an all-or-one batch status. Shared roots are surfaced for later composition/deduplication but no automatic deduplication, distributed scheduling, Provider authority, commit, or canonical RNCS write is performed.
- Added the candidate-only `urrf.universal-art-asset-provenance-license-receipt.v0.1` contract and `verifyUniversalArtAssetProvenanceLicenseReceipt`. `PRODUCTION`/`AAA` provenance and license gates now require an external receipt bound to the exact Genome, Candidate, local inspection, Provider id, seed, and all artifact roots, with explicit source-revision, generator-version, license-scope, and model-weight audit fields; Provider artifact metadata, manifests, and self-declarations cannot satisfy the gate. This does not manufacture legal clearance, auditor identity, key custody, or AAA production proof.
- Added the candidate-only `urrf.universal-art-asset-quality-proof.v0.1` contract and `verifyUniversalArtAssetQualityProof`. `PRODUCTION`/`AAA` quality gates now require an external proof bound to the Genome, Candidate, file inspection, benchmark, hardware profile, and target platform, with local metric equality for LOD0 triangles, texture size, and PBR channels; Provider quality self-declarations cannot satisfy the gate. This remains structural/externally declared candidate evidence, not target-device performance or AAA production proof.
- Added local LOD sequence inspection to the Universal Art Asset Forge. Materialized mesh files now require `lod0`, contiguous levels, a reduction level, and strictly decreasing triangle counts before `lod_gate` can pass; duplicate/non-reducing LODs fail even when Provider evidence says `PASS`. This is structural candidate evidence, not device performance or AAA proof.
- Added the candidate-only `urrf.universal-art-asset-review-receipt.v0.1` contract and `verifyUniversalArtAssetReviewReceipt`. Art-direction and human-art gates now require independently supplied, rooted receipts bound to the exact Genome, Candidate, file-inspection, reference, and comparison roots; Provider self-declarations cannot satisfy either gate. Receipt verification checks contract shape and external-verifier evidence but does not manufacture human approval, perform key custody, or claim AAA production proof.
- Added candidate-only local GLB structural inspection to the Universal Art Asset Forge. Generated/materialized meshes now receive independent accessor, indexed-topology, UV, normal, and GLB material-binding evidence; a bad GLB cannot be promoted by Provider declarations, and the rooted inspection receipt is persisted beside the Forge acceptance artifacts.
- Added the candidate-only `Universal Art Asset Forge` seam. URRF now wraps the existing RAGF Asset Intent/Genome, resolves profile-specific Provider capabilities, executes either the deterministic reference workspace or an injected/external Provider Adapter, materializes provider outputs safely, and emits rooted acceptance plus Evidence Ledger artifacts. Explicit AAA gates cover geometry, topology, UV, PBR, rig/animation, LOD, collision, platform, provenance/license, art direction, runtime projection, quality tier, and human review; unsupported profiles and contract-only runtimes fail closed.
- Added candidate-only URRF art-asset composition recipes: `createLargeWorldArtAssetComposition`, `verifyLargeWorldArtAssetComposition`, and `lowerLargeWorldArtAssetComposition` now expose explicit semantic/geometry/material/biome/style/quality axes, deterministic integer transforms, four style palettes, and up to eight reusable structure/resource parts per asset. Added deterministic multi-asset CPU-reference contact-sheet evidence. This demonstrates combinatorial reuse of existing low-poly prototypes; browser/target-device execution, photorealism, AAA art direction, and canonical-world promotion remain unproven.
- Added `createLargeWorldArtAssetCompositionScene` and `art-asset-composition.v0.1.schema.json`: multiple rooted candidates now lower through one reusable VSR scene seam with shared prototype-mesh deduplication, explicit placement/selection roots, and existing deterministic GLB-bundle verification. This remains candidate-only and does not imply provider authority, target-device execution, or production-grade art quality.
- Added candidate-only Chromium WebGPU evidence for the existing multi-asset PBR material-diversity contact scene. Eight GLB candidates with 32 decoded PBR textures and 40 material-texture bindings now execute through the real browser VSR path with a committed screenshot, receipt, and CPU frame-root comparison. This remains machine-local execution evidence, not target-device performance, physical VRAM, distributed streaming, AAA quality, or canonical-world promotion.
- Added local Chromium WebGPU evidence for aggregate working-set allocation: the rooted `DOWNGRADED_TO_FIT` mixed-quality scene now has a browser-consumable HTML fixture, CPU reference, actual submitted WebGPU receipt, screenshot, and page/shader error checks. This remains machine-local candidate evidence, not target-device performance, distributed scheduling, AAA quality, or canonical-world promotion.
- Added candidate-only aggregate active-working-set allocation: `selectActiveRepresentationPortfolios` now accepts a rooted total resource budget plus minimum-quality and priority maps, deterministically lowers quality to fit, records per-chunk costs/downgrade reasons and initial/final totals, and fails closed as `MINIMUM_REALITY_OVER_BUDGET` when even `PROXY` cannot fit. Added local mixed-quality CPU-reference PNG/report evidence; this is not a distributed scheduler, device telemetry, GPU/AAA grade, or canonical-world write.
- Added a candidate-only four-step large-world visual quality ladder: URRF chunk portfolios now expose `PROXY`, `MOBILE`, `STANDARD`, and `CINEMATIC` slots with explicit integer resource costs and fallback links. Spatial lowering now varies terrain sampling, deterministic prototype complexity, materials, lights, and scene evidence by profile; `REFERENCE` remains unbound. Added deterministic four-profile VSR PNG/report evidence with distinct pixel roots. This is local CPU-reference evidence, not a GPU/AAA visual-quality grade.
