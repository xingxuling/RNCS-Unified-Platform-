# Large World Runtime

`@taowind/large-world-runtime` is the first bounded large-world vertical slice for RNCS. It keeps the world body canonical in RNCS and treats URRF/VSR as representation and projection layers.

The runtime provides deterministic `WorldSeed → Region → Chunk` generation, integer-rooted terrain meshes, a bounded active chunk working set with load/unload hysteresis, URRF candidate materialization, canonical World Time/Event/Fact roots, replayable streaming evidence, and authority-gated Snapshot/Delta replication between isolated runtime instances. Each chunk exposes both a procedural-grid and a wireframe-grid representation candidate; either provider may remain contract-only or execute through an explicit adapter.

This alpha proves a 9×9 region by default, a deterministic two-instance replication loop, a JSON restart boundary that restores the replication idempotency ledger, a bounded authenticated packet link with loss/retry behavior, a deterministic same-base multi-writer conflict court, an atomic durable-bundle store with crash-point recovery, and an optional RNCS Consistency Profile with Authority Lease/Epoch/Fencing admission. It does not claim an MMO-scale distributed world, production network security, distributed consensus, GPU generation, external Spark execution, or production delivery.

## Replication boundary

```js
const base = target.exportReplicationSnapshot();
const delta = source.createReplicationDelta(base);
const receipt = target.applyReplicationDelta(delta, {
  authorityReceipt: {status: 'committed', receipt_root: '<64-hex-root>', epoch: 0}
});
```

`verifyReplicationSnapshot`, `verifyReplicationDelta`, and `verifyReplicationReceipt` seal the three envelopes. A delta is ordered by its base roots, rejects stale or out-of-order application, and is idempotent after the first application. `materializeActive({providerId: LARGE_WORLD_WIREFRAME_PROVIDER_ID})` selects the alternate representation candidate without changing canonical world state.

`exportDurableBundle()` packages the full replication snapshot and applied-delta receipts for a restart boundary. `restoreDurableBundle(bundle, {authorityReceipt})` only restores a pristine runtime after verifying every root and an explicit committed authority receipt; a restored receipt ledger continues to reject duplicate deltas.

`LargeWorldReplicationLink` wraps a transport with `register`, `send`, and optional `advance` methods. It seals packets with an HMAC tag, carries a monotonic sequence, sends authenticated acknowledgements, retries unacknowledged packets, and leaves base-root ordering to RNCS Delta application. The key is caller-supplied test/runtime configuration; it is not persisted in world state.

`resolveReplicationConflict([{delta, writerId, writerSequence}, ...])` sorts same-base candidates by the explicit `lexicographic-writer-priority` policy (`writer_id`, `writer_sequence`, `delta_root`) and returns a candidate-only decision. `applyReplicationConflict(...)` applies only the winner through the normal RNCS Delta gate, records an authoritative conflict receipt, and persists a loser decision so a rejected candidate cannot be applied directly after restart. This is a deterministic local policy, not a distributed consensus protocol.

## URRF representation portfolios

`getRepresentationPortfolio(chunkId)` lowers the chunk's existing URRF references into one canonical RNCS Representation Portfolio. With both built-in references present, the procedural-grid candidate is exposed through `MOBILE`, `STANDARD`, and `CINEMATIC` presentation candidates, while the wireframe-grid candidate remains the `PROXY` minimum-reality slot. The ladder carries biome/environment/material/style axes, integer resource costs, explicit fallback links, and bounded presentation profiles; `REFERENCE` remains unbound until a reference-grade provider and renderer are available. `createChunkRepresentationPortfolio(chunk, {representationObject})` exposes the same lowering seam for callers that already hold a chunk and URRF object.

The portfolio is a candidate description for selection and projection. It does not mutate RNCS world truth, grant provider authority, or claim that the CPU-reference PNG is production GPU/WebGPU quality. A missing reference remains visible as an `INCOMPLETE` composition instead of being silently invented.

`selectActiveRepresentationPortfolios({qualityProfile, qualityByChunk, resourceBudget, resourceBudgetByChunk})` applies the URRF selector to the current bounded active working set and returns a rooted `rncs.large-world-portfolio-selection.v0.1` envelope. The envelope binds every row to the latest `stream_root`, preserves per-chunk selection roots, records minimum-reality fallbacks, and remains candidate-only.

Passing `workingSetResourceBudget` (or `working_set_resource_budget`) adds an aggregate active-working-set budget over the portfolio cost vector (`CPU_MILLI`, `GPU_MILLI`, `NPU_MILLI`, `VRAM_MB`, `RAM_MB`, `STORAGE_KB`, `NETWORK_KB`, `ENERGY_MILLI`). The deterministic priority-weighted greedy allocator lowers one quality step at a time, records the requested/minimum profile, per-chunk cost, priority, downgrade reason, initial/final totals, remaining budget, and rooted policy. `workingSetMinimumQualityProfile`, `workingSetMinimumQualityByChunk`, and `workingSetPriorityByChunk` protect declared minimum reality and high-priority chunks. If even the PROXY minimum cannot fit, the envelope returns `MINIMUM_REALITY_OVER_BUDGET` without mutating RNCS world truth. This is a bounded local allocation proof, not a distributed scheduler, device telemetry, or production performance claim.

The same budgeted selection can be lowered to a browser-consumable VSR scene and checked against an actual local Chromium WebGPU receipt. The committed fixture under `docs/verification/URRF_LARGE_WORLD_WORKING_SET_BUDGET_WEBGPU/` binds the CPU frame root to `submitted: true`, `deviceLost: false`, and a screenshot with no page or shader errors. This is machine-local execution evidence only; target-device performance, distributed scheduling, AAA art quality, and canonical-world promotion remain separate gates.

Passing a verified `resource_governor_plan` (or `resourceGovernorPlan` / `load_shedding_plan`) lowers the v0.3 Power Plane into that same selection envelope. Visual, refinement, and minimum-reality decisions bind by explicit chunk/object candidate IDs (`visual:<chunk_id>`, `refinement:<chunk_id>`, `minimum:<chunk_id>`, or their object-ID forms; the bare chunk/object ID is also accepted). `REDUCE_DETAIL`, `OFFLOAD`, `DEFER`, `DROP`, and `RECOVER_MINIMUM` select the chunk's `PROXY` slot as a candidate minimum-reality fallback; `KEEP`, `FREEZE`, and `REDUCE_FREQUENCY` preserve the requested quality while recording the governor action. Every row records the plan root, binding status, action, and quality override. Unbound chunks remain visible in `unbound_governor_chunk_ids` rather than being silently treated as governed. This is a lowering policy only: it does not perform offload, frequency control, or canonical mutation.

`registerRealityFault()`, `clearRealityFault()`, and `recoverMinimumReality()` close the v0.3 fault-to-representation path. The runtime verifies RNCS RealityFault, MinimumViableReality, PowerProfile, ResourceBudget, ResourceDemand, and LoadSheddingPlan candidates, retains `WORLD_PROXY` when a critical network/power/thermal/provider fault is open, lowers the bounded working set to URRF `PROXY` slots, and emits a rooted `rncs.large-world-minimum-reality-recovery.v0.1` envelope with a VSR spatial scene. `verifyLargeWorldMinimumRealityRecovery()` checks every nested root and the candidate-only authority boundary. Recovery is a local runtime/lowering proof: it does not claim distributed failover, physical telemetry, provider restart, GPU execution, or canonical write authority.

`createRealityHorizon()`, `createRealityInterestGraph()`, `queryReality()` and `createCognitiveWorkingSet()` expose the RNCS/URRF v0.3 access contracts against the generated Chunk query index. `resolveRealityAccess({subject_id, observer, horizon, interest_graph, filters, limit, capacity})` executes the complete candidate lowering: it ranks the indexed Chunks, bounds the CognitiveWorkingSet, turns the selected object IDs into forced Chunk requests, runs the normal load/unload and byte budgets, and returns a rooted `rncs.large-world-reality-access-resolution.v0.1` envelope. This is the access-to-streaming seam; it does not mutate canonical world truth or bypass canonical revalidation.

`createCausalPhysicalProfile()` exposes the v0.3 CausalPhysicalProfile contract for each active Chunk. The demand vector derives independent causal detail `C0`–`C5` and physical detail `P0`–`P5` from task, interaction probability, risk, observation, authority, and event intensity. The selected levels lower to explicit event/physics frequencies, collision and topology behavior, field-solver flags, and integer CPU/GPU/RAM/VRAM/energy costs. `selectActiveRepresentationPortfolios({causal_physical_profile_by_chunk})` subtracts those costs from the same bounded resource budget and records the profile root, execution status, effective budget, and any visual fallback in the rooted selection envelope. This makes high-interaction/high-risk chunks consume more budget and fall back to the proxy minimum-reality slot when the visual budget cannot also admit `STANDARD`; low-demand chunks can retain `STANDARD`. Profiles are candidate-only, preserve safety and RNCS authority, and do not claim production physics, real-device telemetry, or AAA visual quality.

`createSpatialScene({selection, visual_scale})` lowers that envelope and the current active chunks into a rooted `vsr.spatial-scene.v0.4` scene with the `rncs.large-world-spatial-scene.v0.1` extension. The lowering includes profile-specific terrain sampling (`PROXY` / `MOBILE` / `STANDARD` / `CINEMATIC`), deterministic low-poly structure/resource prototypes from `large-world.visual-prototypes.v0.1`, profile-specific candidate materials/lights, streaming cells, and browser-consumable asset references. `visual_scale` is an explicit presentation-only scale (0.25–8) for legibility; authored millimeter dimensions remain recorded as `authoredScale` and RNCS truth is unchanged. `verifyLargeWorldSpatialScene` checks the lowering root, bound profile list, and authority boundary. The result is a VSR projection input; it does not promote representations or write canonical world state.

`createLargeWorldArtAssetComposition(recipe)` defines the reusable URRF art-asset composition seam. A recipe names explicit semantic, geometry, material, biome, style, quality, variant, and integer transform axes; `parts` may reuse the same deterministic prototype or combine up to eight structure/resource parts into one candidate asset. The rooted `urrf.large-world-art-asset-composition.v0.1` envelope is checked by `verifyLargeWorldArtAssetComposition`, and `lowerLargeWorldArtAssetComposition` turns it into a VSR spatial fragment with style/biome-derived materials. `createLargeWorldArtAssetCompositionScene({compositions, placements_mm})` composes multiple rooted assets into a valid VSR scene, deduplicating shared prototype meshes while retaining per-asset materials and placement roots; that scene can be passed to the existing glTF/GLB lowerers. This proves combinatorial reuse without copying geometry or granting provider authority; it is still a low-poly candidate seam, not an AAA asset generator or canonical-world mutation.

`createUniversalArtAssetGenome(input)` wraps the existing RAGF Asset Intent/Genome in a URRF-wide profile contract. The contract names an asset family (`character`, `prop`, `structure`, `environment`, `vegetation`, `resource`, `vehicle`, `creature`, or `vfx`), representation requirements, provider capabilities, budgets, provenance requirements, and explicit AAA acceptance gates. `resolveUniversalArtAssetProvider` exposes a reference RAGF provider or an external provider contract; it never treats a provider manifest as runtime proof.

`createUniversalArtAssetComponentGraph({genome, components})` is the reusable cross-family composition seam. Each component binds its own Universal Genome root, asset-family profile, representation kind (`mesh`, `sdf`, `voxel`, `point-cloud`, `gaussian-splat`, `neural-field`, `curve`, `particle`, `material`, `rig`, or `animation`), integer transform, optional source root, and dependency/attachment edges. The graph is canonically sorted and topologically ordered, rejects unknown references/cycles and authority escalation, and remains candidate-only. `lowerUniversalArtAssetComponentGraph` emits ordered Provider/VSR input nodes with `NOT_EXECUTED` status; it is the semantic composition/lowering contract, not a model runtime, mesh merger, human approval, or AAA visual-quality proof.

`executeUniversalArtAssetComponentGraph({graph, componentGenomes, providersByComponent, outDir})` reuses the existing URRF Provider Pipeline for every component in topological order. A sealed component execution context carries each completed dependency's pipeline/result/output roots into the next Provider request, and each component keeps its own isolated plan, execution receipt, materialized files, and Pipeline Artifact. Missing Genomes, failed dependencies, contract-only Providers, and runtime failures remain explicit per-component blockers; the aggregate is still candidate-only and cannot commit RNCS truth.

`createUniversalArtAssetComponentAssembly({graph, execution, componentExecutions})` packages those per-component Pipeline Artifacts into one candidate-only reusable resource catalog. It preserves graph-local transforms and dependency bindings, prefixes stage-relative files with their isolated stage directory, binds each resource to artifact/output/result roots, and performs local byte-length/SHA-256 verification. A missing resource, unsafe path, stale byte, or incomplete component leaves the package `CANDIDATE_COMPONENT_ASSEMBLY_BLOCKED`; it does not merge meshes, infer absent representations, replace VSR/RSR import compilation, or grant RNCS commit authority.

`lowerUniversalArtAssetComponentAssemblyToRepresentationDirectory({assembly})` projects that catalog into the candidate-only `urrf.universal-art-asset-component-representation-directory.v0.1`. Each entry preserves the exact URRF representation kind, profile, transform, Provider binding, resource paths, and content root, and emits an RNCS `representation-ref` only when a completed Provider stage is actually bound. The VSR view classifies each physical resource by its own role/format (`mesh`, `texture`, `material`, `animation`, `audio`, `shader`, or `other`) while retaining the exact URRF component kind in metadata; a particle, rig, Gaussian, or neural-field component therefore cannot be silently relabeled as a mesh. VSR records retain physical byte length/SHA-256 and can be consumed by the existing local streamer, but direct representation import remains `NOT_EXECUTED` at this layer. The RSR view supplies bounds/LOD/residency observation inputs to the actual observation API while forbidding reconstruction and canonical-state proposals. `verifyUniversalArtAssetComponentRepresentationDirectory` checks the directory against the source assembly and keeps both VSR and RSR downstream of RNCS authority; it is a reusable candidate directory, not a complete AAA importer, renderer, or production asset approval.

`executeUniversalArtAssetComponentRepresentationImport({directory, loadAsset, importers})` is the bounded execution seam behind that `NOT_EXECUTED` marker. A caller may wrap those handlers with `createUniversalArtAssetComponentRepresentationImportRegistry({importers})`, which seals a candidate-only per-kind registry root and keeps the process-local compile/verify bindings explicit; execution reports bind that registry root and reject a portable manifest without its runtime resolver. The runtime rehashes every loaded resource, rejects stale bytes, records `EXECUTED` only after handler verification, and preserves `BLOCKED`/`FAILED`/`NOT_RUN` per component. An executed handler must also declare every loaded catalog asset as either `consumed_asset_ids` or `deferred_asset_ids`; missing, duplicate, cross-component, or silently omitted coverage fails closed. The current integration binds the reusable VSR glTF/PBR component handler, decodes an actual independently materialized four-channel PNG pack, validates matching skeleton-rig and animation-clips manifests against each GLB skin and animation channels, composes two scenes under URRF transforms, and records component-specific `PARTIAL`/`COMPLETE` coverage. The reusable handler also binds per-material packs across a multi-mesh GLB and aggregates multiple independent GLBs with explicit mesh-to-PBR ownership under isolated VSR composition namespaces. The VSR glTF asset package additionally exposes a standalone rig/animation handler; the integration executes a real directory `animation` component into a VSR scene with fused GLB geometry, externally bound rig and animation JSON, validates the skin joint names and parent hierarchy instead of silently selecting a mesh from another stage, and consumes the same-stage four-channel external PBR pack through the reusable glTF/PBR donor when explicitly enabled. It also exposes a particle-preset handler that validates a real RAGF `rsr.particle-preset.v0.4` resource, normalizes an effect-emitter candidate, consumes only that preset, and explicitly defers the component's mesh/PBR/rig/animation resources; `lowerVsrParticleEmitterToSpatialScene()` deterministically lowers that verified emitter into a bounded cross-billboard scene consumed by the existing CPU/WebGPU spatial renderer, with local draw/pixel roots and tamper verification. GPU-native simulation, sprite/flipbook resources, volume rendering, target-device execution and AAA quality remain open. The VSR consumer now also exposes a generic non-mesh descriptor/page candidate handler for `sdf`, `voxel`, `point-cloud`, `gaussian-splat`, `neural-field`, `curve`, and `material`; it seals ordered opaque pages and bounds/content/resource roots with an explicit Draft 2020-12 manifest, and its handler-set factory can bind all seven non-mesh kinds into the URRF registry. A point-cloud candidate using the fixed `application/vnd.vsr.point-cloud.f32rgba.v0.1` record format can then be lowered by `lowerVsrPointCloudCandidateToSpatialScene()` into a bounded transparent cross-billboard scene; a curve candidate using `application/vnd.vsr.curve.polyline.f32rgba.v0.1` can be lowered by `lowerVsrCurveCandidateToSpatialScene()` into a bounded transparent ribbon scene; a voxel candidate with a 16-byte grid header and RGBA8 records using `application/vnd.vsr.voxel.u8rgba.v0.1` can be lowered by `lowerVsrVoxelCandidateToSpatialScene()` into bounded cube nodes; an SDF candidate with a 16-byte grid header and little-endian f32 signed-distance samples using `application/vnd.vsr.sdf.f32grid.v0.1` can be lowered by `lowerVsrSdfCandidateToSpatialScene()` into a bounded CPU marching-tetrahedra surface mesh with gradient normals. Gaussian and neural-field kinds retain `renderStatus=NOT_IMPLEMENTED` until each has a real decoder and renderer. The report and registry are candidate-only and never mutate the representation directory or RNCS world truth.

`generateUniversalArtAsset(input, {outDir, provider})` connects the contract to two real execution paths: the existing deterministic RAGF workspace provider for reference `character`/`prop` candidates, or an injected/external `AssetProviderAdapter` for a real provider process. Both paths emit rooted Genome, provider resolution, execution, candidate, acceptance, and Evidence Ledger files. Materialized GLBs are independently inspected for accessor layout, indexed topology after position welding, UV coverage, finite unit-like normals, and actual GLB material-to-texture bindings; those checks cannot be replaced by Provider metadata. `evaluateUniversalArtAssetAcceptance` still requires LOD/platform/provenance/art-direction/human-review evidence as applicable; provider success alone cannot pass AAA. Unsupported profiles fail closed instead of borrowing a humanoid generator, and no path can write RNCS authoritative world state.

Art-direction and human-art approval use the separate `urrf.universal-art-asset-review-receipt.v0.1` contract. `verifyUniversalArtAssetReviewReceipt` requires an externally supplied, rooted receipt with an explicit review kind, reviewer, external verifier, reference/comparison roots, and bindings to the exact Genome, Candidate, and local file-inspection roots. Provider `art_direction` or `human_review` declarations are retained as ordinary evidence but cannot open either acceptance gate. The verifier checks the contract and root bindings; it does not create a human decision, custody reviewer keys, or turn a synthetic receipt into production AAA proof.

The local file inspector also audits the supplied mesh LOD sequence: a base `lod0`, contiguous levels, at least one reduction level, and strictly decreasing triangle counts are required before a materialized file set can pass `lod_gate`. This prevents a Provider-supplied LOD manifest from masking duplicate or non-reducing geometry; it remains a structural candidate check, not a target-device performance result.

For `PRODUCTION` and `AAA`, `quality_tier_gate` additionally requires an external `urrf.universal-art-asset-quality-proof.v0.1` receipt. The proof binds the exact Genome, Candidate, file-inspection root, benchmark root, hardware profile, and target platform, while its `lod0` triangle count, texture size, and PBR channel count must match the local inspection. Provider `quality_tier=PASS` metadata is ignored for this gate. The verifier checks the contract and metric binding; it does not claim target-device performance, aesthetic quality, or commercial AAA readiness.

For `PRODUCTION` and `AAA`, `provenance_license_gate` additionally requires an external `urrf.universal-art-asset-provenance-license-receipt.v0.1` receipt. The receipt binds the exact Genome, Candidate, local file-inspection root, Provider id, seed, and every candidate artifact root, and records the independently audited source revision, generator version, license scope, and model-weight mode. Artifact-level Provider provenance/license fields, Provider manifests, and Provider `provenance`/`license` declarations are not sufficient for this gate. The verifier checks the receipt contract and bindings; it does not create legal clearance, auditor identity, key custody, or commercial-release approval.

`createUniversalArtAssetEvidenceBundle` packages the four non-substitutable AAA evidence receipts (provenance/license, art direction, quality, and human art review) under one rooted `urrf.universal-art-asset-evidence-bundle.v0.1` envelope. `verifyUniversalArtAssetEvidenceBundle` checks every nested receipt, exact Genome/Candidate/inspection/artifact-root bindings, coverage, and candidate-only authority; an incomplete bundle stays `INCOMPLETE`/`BLOCKED`, and the bundle is only a transport/verification envelope, never a Provider or human authority shortcut. `evaluateUniversalArtAssetAcceptance` can consume a verified bundle, while retaining the same independent gate semantics.

`generateUniversalArtAssetBatch` runs up to 64 asset requests through the existing single-asset Forge, isolates each result under a numbered child directory, and emits a rooted `urrf.universal-art-asset-batch.v0.1` summary with a cross-asset artifact-root index. `verifyUniversalArtAssetBatch` rechecks every embedded Forge result and index; one blocked asset blocks the batch. Shared roots are reported for later composition/deduplication only—the batch is not a distributed scheduler, automatic deduplicating writer, Provider executor, or RNCS canonical-world mutation.

`createUniversalArtAssetAssembly({batch, assetResults, placements_mm, lod_by_asset})` binds actual materialized Forge GLB bytes, local file roots, candidate artifact roots, four PBR channels, selected LODs, and integer millimeter placements into a rooted `urrf.universal-art-asset-assembly.v0.1` envelope. `verifyUniversalArtAssetAssembly` can rehash the current files and rebind the assembly to the source batch; stale bytes, unsafe paths, invalid placements, and invalid LOD selections fail closed. `lowerUniversalArtAssetAssemblyToVsr` emits a bounded `urrf.universal-art-asset-vsr-projection.v0.1` with mesh asset-stream references, dependency-complete external PBR texture records, cells, and meter/mm transforms for a later VSR importer. This is a candidate import/streaming input, not byte-level mesh merging, GPU upload, distributed scheduling, canonical RNCS writing, or AAA proof.

`materializeUniversalArtAssetVsrProjection` reads every selected GLB and external PBR channel into a bounded `urrf.universal-art-asset-vsr-materialization.v0.1` envelope. It returns a VSR catalog whose mesh records depend on four texture records per asset; every payload is checked against declared byte length, SHA-256, and file root before VSR can load it. The local integration then uses `VSRSpatialAssetStreamer`, `parseGlb`, `bindExternalPbrChannelsToGltf`, the real Node PNG decoder, and `importGltfToSpatialSceneAsync` to produce two verified CPU frames with eight decoded textures and ten material-texture bindings, followed by two decoded 160x160 CPU reference-raster PNG outputs with pixel roots. This is local candidate execution/render evidence; no GPU upload, target-device frame time, canonical write, or AAA visual approval is implied.

`createLargeWorldSpatialGltfBundle(scene)` lowers the scene meshes into a deterministic, reusable glTF 2.0 candidate bundle. Each mesh has three explicit LOD payloads, an embedded VSR RGBA swatch texture, a SHA-256 checked streaming record, and a cell index. `verifyLargeWorldSpatialGltfBundle` checks the manifest root, payload hashes, glTF buffer lengths, triangle counts, texture channel, and candidate-only authority boundary. The bundle is an executable provider seam for VSR import/streaming; it is still a low-poly prototype asset source, not an AAA mesh or an authoritative world write.

`createLargeWorldSpatialGlbBundle(scene)` provides the binary counterpart. It reuses RAGF's `GlbBuilder`/`encodeGlb` for each mesh and LOD, embeds a real PNG base-color payload beside the vertex/index buffers, and returns `model/gltf-binary` records that `importGlbToSpatialScene` can consume directly. Passing `{includeRagfShowcase: true}` additionally attaches a real RAGF procedural-3D cinematic candidate with rig, animations, morph data, and four embedded PBR maps; it is an observable provider showcase, not a replacement for world truth or scene geometry. `verifyLargeWorldSpatialGlbBundle` checks the GLB header/JSON, RAGF encoder marker, embedded texture buffer, triangle counts, content hashes, cell index, and candidate-only authority boundary. This closes the provider-to-VSR binary seam locally; it does not claim AAA geometry, compressed textures, device/GPU performance, CDN delivery, or canonical world writes.

Passing `{texture_profile: 'ragf.ktx2-rgba8-mipped.v0.1', texture_size: 32}` selects the opt-in progressive texture profile. RAGF emits a native RGBA8 KTX2 mip container, the GLB binds it through `KHR_texture_basisu`, and each asset records `vsr.progressive-mip-residency.v0.1` hints (VRAM base level, RAM fallback levels, screen-coverage promotion, and cell-unload release). VSR's asynchronous KTX2 decoder imports the levels deterministically. This is a portable residency contract candidate, not BasisU compression or target-device VRAM proof.

Passing `{texture_profile: 'ragf.ktx2-pbr-mipped.v0.1', texture_size: 32}` emits four deterministic KTX2 maps per world mesh (base-color, normal, metallic-roughness/occlusion, and emissive), binds them to the glTF PBR material, and records a residency map for each channel. Base-color/emissive are encoded as sRGB while normal/metallic-roughness use linear RGBA8 KTX2. The four-map path is still candidate-only native RGBA8 KTX2; it does not claim BasisU compression, target-device GPU upload, CDN persistence, or AAA asset quality.

The material-diversity evidence path composes eight selected GLB candidates (terrain, structures, resources, and watchtower) into one VSR contact scene, then runs the same scene through actual local Chromium WebGPU. The committed fixture under `docs/verification/URRF_LARGE_WORLD_PBR_MATERIAL_DIVERSITY/` binds 32 decoded PBR textures and 40 material-texture bindings to a browser receipt whose frame root matches the CPU reference. This is machine-local textured execution evidence only; target-device performance, physical VRAM residency, distributed scheduling, and AAA art quality remain open.

For a fenced cross-node delta, configure the source with `consistencyProfile` and an active `authorityLease`, and configure the receiver with the same profile plus `acceptedAuthorityLease`. `createReplicationDelta(base, {targetNode})` carries the profile root, lease root, epoch, fencing token, source/target node and sequence. `applyReplicationDelta(delta, {authorityReceipt})` requires a committed authority receipt whose lease root and fencing token match the current lease; stale, expired, revoked or owner-mismatched leases fail before any world mutation.

`LargeWorldDurableStore({filePath})` writes a verified durable bundle to a same-directory temporary file, syncs the file, and atomically renames it into place. `save(..., {faultAt: 'after-temp-sync' | 'after-rename'})` is a test-only crash injector; `recover()` keeps a valid primary over an unfinished temporary write or promotes a valid temporary bundle when the primary is missing. Storage receipts are candidate-only and do not replace the committed authority required by `restoreDurableBundle`.
