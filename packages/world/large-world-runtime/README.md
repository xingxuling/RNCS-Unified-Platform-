# Large World Runtime

`@taowind/large-world-runtime` is the first bounded large-world vertical slice for RNCS. It keeps the world body canonical in RNCS and treats URRF/VSR as representation and projection layers.

The runtime provides deterministic `WorldSeed → Region → Chunk` generation, integer-rooted terrain meshes, a bounded active chunk working set with load/unload hysteresis, URRF candidate materialization, canonical World Time/Event/Fact roots, replayable streaming evidence, and authority-gated Snapshot/Delta replication between isolated runtime instances. Each chunk exposes both a procedural-grid and a wireframe-grid representation candidate; either provider may remain contract-only or execute through an explicit adapter.

This alpha proves a 9×9 region by default, a deterministic two-instance replication loop, a JSON restart boundary that restores the replication idempotency ledger, a bounded authenticated packet link with loss/retry behavior, a deterministic same-base multi-writer conflict court, an atomic durable-bundle store with crash-point recovery, and an optional RNCS Consistency Profile with Authority Lease/Epoch/Fencing admission. It does not claim an MMO-scale distributed world, production network security, distributed consensus, GPU generation, external Spark execution, or production delivery.

## Replication boundary

```js
const base = target.exportReplicationSnapshot();
const delta = source.createReplicationDelta(base);
const receipt = target.applyReplicationDelta(delta, {
  authorityReceipt: {status: 'committed', receipt_root: '<64-hex-root>', epoch: 0}
});
```

`verifyReplicationSnapshot`, `verifyReplicationDelta`, and `verifyReplicationReceipt` seal the three envelopes. A delta is ordered by its base roots, rejects stale or out-of-order application, and is idempotent after the first application. `materializeActive({providerId: LARGE_WORLD_WIREFRAME_PROVIDER_ID})` selects the alternate representation candidate without changing canonical world state.

`exportDurableBundle()` packages the full replication snapshot and applied-delta receipts for a restart boundary. `restoreDurableBundle(bundle, {authorityReceipt})` only restores a pristine runtime after verifying every root and an explicit committed authority receipt; a restored receipt ledger continues to reject duplicate deltas.

`LargeWorldReplicationLink` wraps a transport with `register`, `send`, and optional `advance` methods. It seals packets with an HMAC tag, carries a monotonic sequence, sends authenticated acknowledgements, retries unacknowledged packets, and leaves base-root ordering to RNCS Delta application. The key is caller-supplied test/runtime configuration; it is not persisted in world state.

`resolveReplicationConflict([{delta, writerId, writerSequence}, ...])` sorts same-base candidates by the explicit `lexicographic-writer-priority` policy (`writer_id`, `writer_sequence`, `delta_root`) and returns a candidate-only decision. `applyReplicationConflict(...)` applies only the winner through the normal RNCS Delta gate, records an authoritative conflict receipt, and persists a loser decision so a rejected candidate cannot be applied directly after restart. This is a deterministic local policy, not a distributed consensus protocol.

## URRF representation portfolios

`getRepresentationPortfolio(chunkId)` lowers the chunk's existing URRF references into one canonical RNCS Representation Portfolio. The large-world runtime currently maps its procedural-grid reference to a `STANDARD` slot and its wireframe-grid reference to a `PROXY` slot, with biome/environment/material/style axes, integer resource costs, and a proxy minimum-reality fallback. `createChunkRepresentationPortfolio(chunk, {representationObject})` exposes the same lowering seam for callers that already hold a chunk and URRF object.

The portfolio is a candidate description for selection and projection. It does not mutate RNCS world truth, grant provider authority, or claim that the CPU-reference PNG is production GPU/WebGPU quality. A missing reference remains visible as an `INCOMPLETE` composition instead of being silently invented.

`selectActiveRepresentationPortfolios({qualityProfile, qualityByChunk, resourceBudget, resourceBudgetByChunk})` applies the URRF selector to the current bounded active working set and returns a rooted `rncs.large-world-portfolio-selection.v0.1` envelope. The envelope binds every row to the latest `stream_root`, preserves per-chunk selection roots, records minimum-reality fallbacks, and remains candidate-only.

Passing a verified `resource_governor_plan` (or `resourceGovernorPlan` / `load_shedding_plan`) lowers the v0.3 Power Plane into that same selection envelope. Visual, refinement, and minimum-reality decisions bind by explicit chunk/object candidate IDs (`visual:<chunk_id>`, `refinement:<chunk_id>`, `minimum:<chunk_id>`, or their object-ID forms; the bare chunk/object ID is also accepted). `REDUCE_DETAIL`, `OFFLOAD`, `DEFER`, `DROP`, and `RECOVER_MINIMUM` select the chunk's `PROXY` slot as a candidate minimum-reality fallback; `KEEP`, `FREEZE`, and `REDUCE_FREQUENCY` preserve the requested quality while recording the governor action. Every row records the plan root, binding status, action, and quality override. Unbound chunks remain visible in `unbound_governor_chunk_ids` rather than being silently treated as governed. This is a lowering policy only: it does not perform offload, frequency control, or canonical mutation.

`registerRealityFault()`, `clearRealityFault()`, and `recoverMinimumReality()` close the v0.3 fault-to-representation path. The runtime verifies RNCS RealityFault, MinimumViableReality, PowerProfile, ResourceBudget, ResourceDemand, and LoadSheddingPlan candidates, retains `WORLD_PROXY` when a critical network/power/thermal/provider fault is open, lowers the bounded working set to URRF `PROXY` slots, and emits a rooted `rncs.large-world-minimum-reality-recovery.v0.1` envelope with a VSR spatial scene. `verifyLargeWorldMinimumRealityRecovery()` checks every nested root and the candidate-only authority boundary. Recovery is a local runtime/lowering proof: it does not claim distributed failover, physical telemetry, provider restart, GPU execution, or canonical write authority.

`createRealityHorizon()`, `createRealityInterestGraph()`, `queryReality()` and `createCognitiveWorkingSet()` expose the RNCS/URRF v0.3 access contracts against the generated Chunk query index. `resolveRealityAccess({subject_id, observer, horizon, interest_graph, filters, limit, capacity})` executes the complete candidate lowering: it ranks the indexed Chunks, bounds the CognitiveWorkingSet, turns the selected object IDs into forced Chunk requests, runs the normal load/unload and byte budgets, and returns a rooted `rncs.large-world-reality-access-resolution.v0.1` envelope. This is the access-to-streaming seam; it does not mutate canonical world truth or bypass canonical revalidation.

`createCausalPhysicalProfile()` exposes the v0.3 CausalPhysicalProfile contract for each active Chunk. The demand vector derives independent causal detail `C0`–`C5` and physical detail `P0`–`P5` from task, interaction probability, risk, observation, authority, and event intensity. The selected levels lower to explicit event/physics frequencies, collision and topology behavior, field-solver flags, and integer CPU/GPU/RAM/VRAM/energy costs. `selectActiveRepresentationPortfolios({causal_physical_profile_by_chunk})` subtracts those costs from the same bounded resource budget and records the profile root, execution status, effective budget, and any visual fallback in the rooted selection envelope. This makes high-interaction/high-risk chunks consume more budget and fall back to the proxy minimum-reality slot when the visual budget cannot also admit `STANDARD`; low-demand chunks can retain `STANDARD`. Profiles are candidate-only, preserve safety and RNCS authority, and do not claim production physics, real-device telemetry, or AAA visual quality.

`createSpatialScene({selection, visual_scale})` lowers that envelope and the current active chunks into a rooted `vsr.spatial-scene.v0.4` scene with the `rncs.large-world-spatial-scene.v0.1` extension. The lowering includes decimated proxy terrain, standard terrain, deterministic low-poly structure/resource prototypes from `large-world.visual-prototypes.v0.1`, streaming cells, lights, and browser-consumable asset references. `visual_scale` is an explicit presentation-only scale (0.25–8) for legibility; authored millimeter dimensions remain recorded as `authoredScale` and RNCS truth is unchanged. `verifyLargeWorldSpatialScene` checks the lowering root and authority boundary. The result is a VSR projection input; it does not promote representations or write canonical world state.

`createLargeWorldSpatialGltfBundle(scene)` lowers the scene meshes into a deterministic, reusable glTF 2.0 candidate bundle. Each mesh has three explicit LOD payloads, an embedded VSR RGBA swatch texture, a SHA-256 checked streaming record, and a cell index. `verifyLargeWorldSpatialGltfBundle` checks the manifest root, payload hashes, glTF buffer lengths, triangle counts, texture channel, and candidate-only authority boundary. The bundle is an executable provider seam for VSR import/streaming; it is still a low-poly prototype asset source, not an AAA mesh or an authoritative world write.

`createLargeWorldSpatialGlbBundle(scene)` provides the binary counterpart. It reuses RAGF's `GlbBuilder`/`encodeGlb` for each mesh and LOD, embeds a real PNG base-color payload beside the vertex/index buffers, and returns `model/gltf-binary` records that `importGlbToSpatialScene` can consume directly. Passing `{includeRagfShowcase: true}` additionally attaches a real RAGF procedural-3D cinematic candidate with rig, animations, morph data, and four embedded PBR maps; it is an observable provider showcase, not a replacement for world truth or scene geometry. `verifyLargeWorldSpatialGlbBundle` checks the GLB header/JSON, RAGF encoder marker, embedded texture buffer, triangle counts, content hashes, cell index, and candidate-only authority boundary. This closes the provider-to-VSR binary seam locally; it does not claim AAA geometry, compressed textures, device/GPU performance, CDN delivery, or canonical world writes.

Passing `{texture_profile: 'ragf.ktx2-rgba8-mipped.v0.1', texture_size: 32}` selects the opt-in progressive texture profile. RAGF emits a native RGBA8 KTX2 mip container, the GLB binds it through `KHR_texture_basisu`, and each asset records `vsr.progressive-mip-residency.v0.1` hints (VRAM base level, RAM fallback levels, screen-coverage promotion, and cell-unload release). VSR's asynchronous KTX2 decoder imports the levels deterministically. This is a portable residency contract candidate, not BasisU compression or target-device VRAM proof.

Passing `{texture_profile: 'ragf.ktx2-pbr-mipped.v0.1', texture_size: 32}` emits four deterministic KTX2 maps per world mesh (base-color, normal, metallic-roughness/occlusion, and emissive), binds them to the glTF PBR material, and records a residency map for each channel. Base-color/emissive are encoded as sRGB while normal/metallic-roughness use linear RGBA8 KTX2. The four-map path is still candidate-only native RGBA8 KTX2; it does not claim BasisU compression, target-device GPU upload, CDN persistence, or AAA asset quality.

For a fenced cross-node delta, configure the source with `consistencyProfile` and an active `authorityLease`, and configure the receiver with the same profile plus `acceptedAuthorityLease`. `createReplicationDelta(base, {targetNode})` carries the profile root, lease root, epoch, fencing token, source/target node and sequence. `applyReplicationDelta(delta, {authorityReceipt})` requires a committed authority receipt whose lease root and fencing token match the current lease; stale, expired, revoked or owner-mismatched leases fail before any world mutation.

`LargeWorldDurableStore({filePath})` writes a verified durable bundle to a same-directory temporary file, syncs the file, and atomically renames it into place. `save(..., {faultAt: 'after-temp-sync' | 'after-rename'})` is a test-only crash injector; `recover()` keeps a valid primary over an unfinished temporary write or promotes a valid temporary bundle when the primary is missing. Storage receipts are candidate-only and do not replace the committed authority required by `restoreDurableBundle`.
