# 动画、音频与特效命名边界反演报告 v0.4

## 1. 异常

传统游戏引擎把动画、音频和特效分成三个独立编辑器与运行时：

- 动画系统负责关键帧、骨骼与状态机；
- 音频系统负责声源、总线和混音；
- 特效系统负责粒子、屏幕效果和后处理。

但实际创作中，它们反复围绕同一个问题工作：某个现实事件在什么时候发生、由谁触发、持续多久、对不同观察者应该如何被感知，以及如何与世界状态保持同步。

## 2. 命名边界扫描

### 动画隐含的旧边界

“动画”通常被限定为视觉对象属性随时间变化，排除了：

- 行为意图与状态转换原因；
- 动画标记对世界因果的影响；
- 同一动作在声音、粒子、触觉中的等价投影；
- 可恢复、可重放和可证明的时间连续性。

### 音频隐含的旧边界

“音频”通常被限定为播放音频文件，排除了：

- 声音与因果事件的语义关系；
- 观察者位置、权限与可听范围；
- 声学输出的确定性计划与证据；
- 无音频资产时由规则合成可验证声音。

### 特效隐含的旧边界

“特效”通常被限定为视觉装饰，排除了：

- 特效作为状态变化的感知证据；
- 对玩家、调试者和无障碍观察者的不同投影；
- 粒子与屏幕效果的可重放因果来源；
- 与动画标记、物理碰撞和 Agent 行为的统一触发。

## 3. 反演结果

三者被压缩为一个共同结构：

```text
现实事件 / 主体意图
        ↓
确定性时间与状态转换
        ↓
体验绑定图
        ↓
动画投影 + 声学投影 + 特效投影
        ↓
观察者相对体验
        ↓
快照、重放、Evidence 与 RFE 候选因果
```

新名称：

> **Temporal Experience Fabric（时序体验织构）**

定义：

> 在同一确定性时间与因果事件流上，编排动作、声音、粒子、屏幕反馈和观察者差异，并生成可恢复、可重放、可验证的多模态体验候选。

## 4. 最小原语

- `Experience Event`：真实发生或候选发生的语义事件；
- `Timeline Tick`：跨动画、音频、特效共享的确定性时间单位；
- `Animation State`：主体动作和属性的时间状态；
- `Marker`：动画时间中的语义事件锚点；
- `Audio Cue`：事件到声学计划的映射；
- `Effect Graph`：事件到粒子与屏幕信号的映射；
- `Binding`：事件与多模态动作之间的关系；
- `Observer Projection`：按角色、权限、设备与无障碍需要生成体验；
- `Experience Root`：动画、音频、特效和事件连续性的内容根。

## 5. 与现有栈的边界

```text
RFE
决定哪些事件和状态变化具有权威

RSR Embodied Dynamics
产生碰撞、关节、场和具身动作候选

Temporal Experience Fabric v0.4
把权威或候选事件编译成时间化多模态体验

VSR
把视觉体验投影成设备可执行画面

HNAF/HNAC
把体验能力跨宿主封装与执行
```

时序体验织构不宣布现实事实成立，也不修改物理权威；它输出体验状态和可审计的候选因果增量。

## 6. 本版验证

本版不是概念命名，已经实现：

- 关键帧、缓动、Hermite 切线与弹簧插值；
- 动画状态机、条件、触发器、退出时间、优先级和交叉淡化；
- Override / Additive 动画层；
- 二维骨骼层级和双骨 IK；
- 动画 Marker 驱动语义事件；
- 振荡器、噪声、内联采样、ADSR、空间声像、总线、低通和延迟；
- PCM 16-bit 立体声 WAV 离线渲染；
- Burst / Rate 粒子发射、生成形状、速度、重力、阻力、曲线、碰撞和生命周期；
- Shake、Flash、Chromatic Aberration、Time Dilation 屏幕信号；
- 玩家、调试者、审计者、无障碍观察者投影；
- Snapshot、Replay、Recovery 和 RFE CausalDelta。

## 7. 反证与剩余边界

当前实现仍是 TypeScript 参考运行时，不等同于成熟商业引擎的动画、DSP 和 GPU 粒子系统：

- 没有 GPU 粒子计算和批量实例渲染；
- 没有音频设备实时输出和硬实时 DSP 线程；
- 没有压缩动画流、蒙皮网格和动画重定向；
- 没有 HRTF、卷积混响和音频遮挡；
- 没有 GPU 后处理 Render Graph；
- VSR CPU 软件光栅在大量粒子和阴影下吞吐有限。

这些限制被写入状态文件和基准，不以演示画面掩盖。

## 8. 锚点

> 动画不是让模型动，音频不是播放文件，特效不是装饰画面。三者本质上是现实事件在时间轴上面向观察者生成的多模态感知证据。
