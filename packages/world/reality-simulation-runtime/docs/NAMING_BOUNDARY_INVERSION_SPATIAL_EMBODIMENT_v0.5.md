# 命名边界反演：从“三维物理”到“空间具身现实”

传统三维物理引擎常把身体拆成刚体、角色控制器、骨骼、声音和震动。对神经接口虚拟世界而言，这些不是五件独立的事情，而是主体身体的一次状态变化被不同器官感知。

```text
接触发生
→ 身体速度和姿态改变
→ 世界确认接触事实
→ 耳朵获得空间声音
→ 身体区域获得触觉
→ 主体形成下一次意图
```

v0.5 因此以“具身状态”为中心：物理接触是源事件，声音与触觉是观察者相对投影，RFE CausalDelta 只承载需要成为权威事实的结果。

## 反演结果

- 刚体不是孤立数学对象，而是主体或物体的空间身体；
- 角色控制器不是键盘适配器，而是意图到身体运动的安全转换；
- 空间声音和触觉不是附加特效，而是同一世界事件的感知投影；
- RSR Tick 是候选模拟时间，不等于 RFE Generation；
- VSR 只投影身体状态，不决定什么事实真实成立。
