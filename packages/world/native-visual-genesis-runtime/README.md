# Native Visual Genesis Runtime

This package is the Phase 6 RNCS-native visual execution boundary. It derives a renderable character body from Character Genome, samples a typed performance plan, resolves a scene/camera field and compiles Anime style laws before producing deterministic PNG frame evidence.

The package does not call an external visual generation model. External providers remain candidate compatibility adapters and cannot write Episode or Character Genome authority.

The public chain is:

`Character Genome -> Character Visual Genome -> Character Body Graph -> Performance Frame -> Scene Frame -> Style Projection -> Native Frame`

The first backend is a CPU-safe RNCS Custom 2D/2.5D renderer. It emits color, depth, mask, line and light evidence and can close a real FFmpeg/ffprobe MP4 gate through `buildNativeShot`.

Provider capability fields are defined in `schemas/native-provider-manifest.v0.1.schema.json`. A provider must expose its input/output types, resolution, frame rate, determinism, seed support, continuity and motion behavior, CPU/GPU needs, timeout, cost, failure modes and evidence outputs before it can be used in a build.
