# @taowind/world-body-formal-theory

The joint theory composes the RSR and VSR five-level theories into ten cross-layer theorems, `WB-T1` through `WB-T10`.

It checks root closure, BodyMap totality, authority non-interference, exactly-once event routing, authority-to-presentation commutation, snapshot rollback, render graph safety, branch/observer isolation, and compositional refinement. `WB-T10` remains explicitly unverified until the entire declared real VM/backend/GPU chain is executed.
