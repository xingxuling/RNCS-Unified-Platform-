## 关键决定

1. 状态根排除时间、Replica 与 Generation，使语义等价可跨宿主验证。
2. 快照根保留历史位置，使连续性可追溯。
3. device-private 与 ephemeral 不提供“危险开关”，从实现层禁止导出。
4. secret 不允许明文导出，必须进入 AES-GCM 认证加密信封。
5. 冲突不会被静默覆盖；每个差异生成 `conflict_root`。

## 下一阶段

```text
→ 语义交互树

```

同时由 Reality One Gateway 接入 v0.5 状态包，让 HNAF Pocket 与桌面会话通过 Generation 同步。
