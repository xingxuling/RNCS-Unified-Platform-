# HNAC / HNAF v0.8+ 路线

## v0.8：远程 Provider 与执行沙盒

- HTTP / WebSocket / stdio / local-process Provider；
- Provider 描述签名和来源证明；
- 超时、重试、熔断、幂等与取消；
- 资源配额和沙盒策略；
- 回执与 RFE Generation 正式绑定。

## v0.9：分布式能力目录

- 多节点 Provider 注册与租约；
- 健康检查和动态下线；
- 信任、地域、隐私、成本和延迟联合调度；
- 跨组织最小披露能力协商。

## v1.0 候选：现实能力运行平面

- HNAC 应用、Agent、云服务和设备共享执行协议；
- AAF 委托、撤销和多人批准进入正式链；
- RFE 保存权威状态变化与恢复点；
- Gateway 支持生产级审计和运行时隔离；
- 完成一个非游戏应用和一个真实硬件样板。

## 反证门

如果动态能力协商长期显著慢于固定 API、故障率更高、调试更困难，且不能带来可替换性、安全或连续性收益，则应把 CNP 降级为部署期编译器，而不是每次执行的运行时层。
