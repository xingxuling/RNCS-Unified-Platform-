# 30｜HNAC/HNAF v0.8 工程验收报告

## 实现范围

- Manifest 0.8 与 Schema；
- Python Remote Execution Fabric；
- CNP/AAF 授权链复用；
- RNCS Envelope；
- RFE Core SDK 原生提交；
- HTTP、WebSocket、本地进程与 builtin 实跑；
- Browser remote execution module；
- Pocket v0.5 native bridge contract。

## 自动化结果

- 总测试：54；
- 通过：54；
- 失败：0。

## 安全验收

- 未签名 Provider 可按策略拒绝；
- 已签名描述符被篡改后拒绝；
- 本地进程需显式批准；
- 网络主机与可执行文件受白名单限制；
- 超时进程被终止；
- 取消在执行前或尝试间生效；
- 同一幂等键不生成第二个 RFE Generation；
- 达到失败阈值后 Provider 熔断。

## 连续性验收

成功执行回执通过 RNCS proposal、AAF 参考策略与 RFE Core SDK 形成新 Generation。测试中连续两次不同幂等调用生成 Generation 1 与 2；重复幂等调用不增加 Generation。
