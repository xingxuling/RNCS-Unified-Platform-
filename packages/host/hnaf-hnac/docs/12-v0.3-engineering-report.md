## Truth boundary

The v0.3 host is implemented with Wasmtime's Python Component Model API. A Rust-native host was not falsely claimed or shipped without compilation evidence.

## Architectural result

The application object no longer depends on the implementation language of its host. Python is now merely one host projection, not the definition of HNAC.
