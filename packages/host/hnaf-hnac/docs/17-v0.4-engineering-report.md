# HNAF / HNAC v0.4 Engineering Report

## Delivered

v0.4 introduces the first independently implemented HNAC host and the first installable device-spanning projection.

### JavaScript/Node host

- dependency-free deterministic ZIP reader;
- duplicate and traversal path rejection;
- SHA-256 canonical file-map verification;
- Ed25519 signature verification from raw public keys;
- host-profile negotiation;
- capability lease issuance;
- Core Wasm ABI execution;
- declarative fallback execution;
- app-identity-scoped KV state;
- semantic JSONL traces.

### Browser/PWA host

- local `.hnac` importer and embedded capsule loader;
- offline shell and installable PWA manifest;
- browser WebCrypto verification;
- browser WebAssembly execution;
- origin-scoped capability adapters;
- AIP semantic graph renderer;
- responsive desktop, tablet, and phone shell.

### Conformance and projection tooling

- `hnac conformance` cross-host semantic trace gate;
- `hnac project-web` reversible PWA projection compiler;
- signed v0.4 portable-host example;
- host implementation and trace contracts.

## Verified behavior

The Python and JavaScript hosts execute the same signed capsule using the same Core Wasm entry. After volatile values are removed, their ordered semantic traces are identical.

The browser runtime is also executed under Node's browser-compatible Web APIs during the automated suite. It verifies the signature, negotiates Core Wasm, invokes the expected capabilities, and completes successfully.

## Explicit non-claims

- The Rust host is not claimed complete because the build environment has no Rust toolchain and cannot fetch one.
- The browser host does not claim Component Model support.
- PWA projection does not make the web shell canonical.
- JavaScript hosts do not claim fuel metering.
- Windows, macOS, Android, and Apple store packages are not yet generated.

## Test result

`24 passed` before release packaging, covering all v0.1-v0.3 compatibility tests plus v0.4 host, projection, conformance, browser, tamper, and unsupported-profile tests.
