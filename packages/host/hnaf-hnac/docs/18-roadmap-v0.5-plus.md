# Roadmap after v0.4

## v0.4.1 — Rust host equivalence gate

- compile a Rust Wasmtime Component host;
- use generated WIT bindings;
- consume the same host implementation contract;
- compare Rust and Python Component traces;
- add typed resource handles, destructor tests, and strict fuel/memory policy reports.

## v0.5 — Portable State Fabric

- content-addressed state snapshots;
- portable, device-private, secret, cache, and ephemeral partitions;
- deterministic migration graph;
- encrypted export/import;
- replica identity, conflict records, and reconciliation policies;
- state conformance across Python, JavaScript, and browser hosts.

## v0.6 — Adaptive Interface Projection

- typed action, information, navigation, document, media, and spatial nodes;
- interaction-intent routing independent of mouse/touch/voice/neural input;
- desktop, tablet, phone, accessibility, and spatial renderers;
- layout constraints and semantic snapshot tests.

## v0.7 — Desktop Distribution Projection

- Windows and macOS host shells;
- reversible MSIX and `.app` materialization;
- capability-to-entitlement mapping;
- projection provenance and local uninstall rollback.

## v0.8 — Mobile Distribution Projection

- Android and iOS/iPadOS host shells;
- lifecycle and background-work semantic bridge;
- sensor, notification, file, and camera capability contracts;
- AAB and Xcode project projections.

## v0.9 — Trust and Update Graph

- delegated and threshold signing roles;
- key rotation and revocation;
- rollback protection;
- transparency log and provenance adapters;
- delta capsule transport while preserving canonical roots.
