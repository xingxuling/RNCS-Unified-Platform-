# v0.2 Engineering Report

## Objective

Replace the v0.1 declarative proof executor with genuine WebAssembly execution without changing the outer application-object boundaries.

## Result

The objective passed. The following v0.1 concepts remained intact:

- deterministic capsule;
- integrity index;
- Ed25519 trust seed;
- manifest-driven capabilities;
- deny-by-default broker;
- app-scoped state;
- CLI pack/sign/verify/run flow.

The execution layer was replaced by a Wasmtime-backed module and new executor interface. v0.1 capsules still execute through the compatibility adapter.

## Added evidence

- real Wasm binary execution;
- Wasm-to-host capability calls;
- imported-capability firewall;
- execution fuel and memory ceilings;
- host-profile negotiation;
- pre-launch fallback selection;
- signature policy enforcement;
- semantic execution trace;
- clean package installation and project initialization.

## Automated validation

Seven unit tests cover:

1. pack, sign, verify, execute, state, and trace;
2. tamper detection;
3. undeclared imported capability rejection;
4. nonterminating guest fuel exhaustion;
5. restricted-host execution fallback;
6. host signature policy;
7. v0.1 runtime compatibility.

A separate clean virtual-environment smoke test validates package installation, `hnac init`, packing, and execution.
