# 31｜v0.9+ 路线

## v0.9：多节点连续执行

- Provider lease 与短期凭证；
- 流式回执和长任务 checkpoint；
- 分布式幂等与租约续期；
- Provider 健康、延迟、成本和信誉统计；
- RFE pending → committed 两阶段提交；
- 断线恢复和跨设备接管。

## v1.0 收口条件

- 0.1–0.9 兼容矩阵稳定；
- 桌面、浏览器、Android 至少三类宿主；
- 一个非游戏现实应用样板；
- 一个持续游戏后端样板；
- 一个低风险真实设备闭环；
- 供应链、权限、执行、证据和恢复全链验收。

## 暂不进入

- 自研通用操作系统；
- 工业/医疗/汽车直接控制；
- 侵入式神经硬件。
