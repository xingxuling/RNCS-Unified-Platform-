## 3. 关键不变量

1. AIP 图必须通过 Schema、引用和无环检查；
2. 隐藏规则不能让根节点消失；
3. 投影由规范化输入决定，相同 Host Profile 必须产生相同语义快照；
4. 宿主不支持某输入模式时必须显式返回 `unsupported-mode`；
5. 多个意图同时匹配时必须返回 `ambiguous`，不得静默猜测；
6. 未知事件返回 `unresolved`；
7. v0.6 不改变 v0.5 的状态分区与导出安全边界；
8. PWA 只是可逆宿主投影，不是新的应用本体。
