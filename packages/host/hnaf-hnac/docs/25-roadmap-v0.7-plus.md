# HNAF / HNAC v0.7+ 路线

## v0.7：宿主能力实时绑定

目标：让 AIP 节点不只形成界面，还能按宿主资源动态绑定本地、云端、Agent 或硬件 Provider。

优先项：

- 运行期 Capability Registry；
- AIP `action.intent` → CNP/Gateway Provider 绑定；
- 权限、风险、确认和证据钩子；
- Provider 故障切换；
- 本地优先与离线策略；
- Android/桌面原生宿主适配器。

## v0.8：多宿主连续会话

- 设备间会话接力；
- 增量状态复制；
- Generation 通知；
- 多设备冲突可视化；
- 同一意图在不同宿主继续执行。

## v0.9：具身与空间宿主

- XR 空间控件映射；
- 眼动、手势、语音、触觉事件；
- 身体与空间锚点连续性；
- 感知降级与无障碍等价；
- RSR/VSR 体验投影接入。

## 进入 v1.0 的门槛

1. 至少三个真实宿主：浏览器、Android、桌面；
2. 一个完整普通应用和一个游戏样板；
3. 状态、界面、能力三类跨宿主语义等价；
4. 长期运行、升级、故障恢复和签名连续性证据；
5. 普通用户无需理解 HNAC 内部项目即可完成核心任务。
