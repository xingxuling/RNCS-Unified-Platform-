## 性能说明

本轮没有把单机微秒或毫秒数据包装成生产性能结论。能力协商、权威裁决和 HTTP Gateway 的时延受 Provider 数量、策略规模、网络、签名验证与存储后端影响；当前证据只证明功能闭环和确定性语义。
