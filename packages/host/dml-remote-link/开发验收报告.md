# DML Remote Link v0.3.0-alpha.1 开发验收报告

## 验收结论

**PASS（Alpha）**

## 已验证闭环

```text
一次性 Browser 连接码
→ P-256 浏览器设备注册
→ Relay 签发 Ed25519 短期 Grant
→ Lovable 型 Semantic Action
→ Relay 队列
→ 本机 Host 签名拉取
→ DML Core 真实执行
→ Host 签名回执
→ Workbench Projection
```

## 自动测试

- 一次性码只能使用一次；
- 未授权浏览器被拒绝；
- Origin 不匹配被拒绝；
- 浏览器设备签名可刷新短期 Grant；
- 撤销设备后现有 Grant 被拒绝；
- Host 签名与 nonce 重放拒绝；
- Semantic Action 到 DML Core 的端到端闭环；
- Host Policy 身份剥离与目录映射。

## 部署交付

- Cloudflare Named Tunnel PowerShell 配置；
- 固定 hostname 到 `127.0.0.1:17901`；
- Relay、Host、Tunnel 一键启动；
- Windows 登录自启动任务；
- Lovable 一次性连接对话框与设备密钥客户端。
