# DML Remote Link v0.2 协议

## 浏览器通道

基础地址：

```text
https://relay.example.com/v1/sessions/<session_id>
```

请求头：

```text
Authorization: Bearer <browser_token>
```

传输资源：

- `GET /projection`：读取最新现实投影。
- `GET /events`：订阅 SSE 投影与回执事件。
- `POST /intent`：提交 DML Semantic Action。
- `GET /status`：读取 Host 在线状态与队列状态。

这些路径是传输适配，不是固定业务 API。业务语义由 Action Contract 决定。

## Host 配对

Host 首次生成 Ed25519 密钥对，并以一次性 `pair_code` 注册公钥。配对完成后，pair code 立即失效。

## Host 请求签名

签名文本：

```text
METHOD
PATH_WITH_QUERY
TIMESTAMP_MS
NONCE
SHA256(BODY)
```

请求头：

```text
X-DML-Host-ID
X-DML-Timestamp
X-DML-Nonce
X-DML-Signature
```

Relay 拒绝超时请求、重复 nonce、未知 Host 或无效签名。

## 动作信封

Relay 将浏览器 Action 封装为 `dml.remote-action.v0.2`，增加：

- session 与 sequence；
- idempotency key；
- 过期时间；
- canonical root；
- Relay Ed25519 signature。

Host 验签、检查过期时间，再进入本地策略和 DML Runtime。

## 执行回执

Host 返回 `dml.remote-result.v0.2`：

- action root；
- execution result；
- Workbench projection；
- started/completed time；
- projection evidence root；
- Host signature。

Relay 验签后才更新投影并推送给浏览器。
