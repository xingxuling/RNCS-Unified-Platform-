# RFE v1.0.0 发布说明

## 版本跃迁

v0.9 解决固定联盟在网络分区后如何恢复。v1.0 解决联盟自身如何变化而不切断现实连续性。

C12 不把“配置文件替换”视为普通运维操作，而把它提升为一种必须被旧权威授权、新权威接受、密钥连续性证明并留下可恢复证据的权威状态转换。

## 验收结果

- C1–C12 JavaScript 回归：41/41 PASS；
- C12 冻结向量验证：PASS；
- 旧授权权重：7/7；
- 新接受权重：8/7；
- 中断位置：第 2/5 个拓扑记录之后；
- 恢复：完成剩余 3 个记录；
- 重复恢复：receipt hash 不变；
- 新配置确认权重：8/7；
- 最终 epoch：2；
- 拓扑分歧：0。

## 非目标

v1.0 不包含：

- 生产级 PKI 或硬件密钥托管；
- 自动发现节点；
- 无限制并发配置提案；
- 任意永久网络分区下的活性保证；
- 应用层 UI、HNAC/HNAF 投影或业务工作流。
