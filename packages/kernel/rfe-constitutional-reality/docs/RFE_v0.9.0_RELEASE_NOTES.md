# RFE v0.9.0 发布说明

## 一句话

RFE v0.9.0 让拜占庭联邦现实在网络分区和进程中断后，仍能保持锁安全、切换视图并恢复到唯一权威连续性。

## 版本边界

v0.9.0 只新增 C11，不扩张 UI、意图编译、宿主适配或应用层职责。其目标是把 v0.8 的“同轮冲突安全”推进到“跨视图停滞恢复”。

## 实现资产

- 零依赖 JavaScript 参考运行时；
- 独立 Rust `rfe-partition-healing` crate；
- Rust 原生一致性测试入口；
- C11 冻结 JSON 向量；
- 独立结果验证器；
- JS/Rust benchmark 入口；
- 持久状态、崩溃注入与恢复测试；
- 一键验证与源码审计命令。

## 已执行证据

当前构建环境已执行：

- JavaScript 语法检查：PASS；
- JavaScript 回归测试：29/29 PASS；
- C11 向量验证：PASS；
- 200 次 C11 完整闭环 benchmark；
- 仓库静态结构与依赖审计。

## 未执行边界

当前构建容器没有 Rust/Cargo，且网络策略阻止保存工具链组件，因此 Rust 源码未在本容器编译。发布包保留完整 crate、测试、示例和锁文件，但不会将其标记为原生运行通过。
