# RFE v1.0.0 — Constitutional Reality

**中文名：宪法现实 / 权威拓扑演化现实**  
**冻结语义级别：C1–C12**  
**新增闭环：C12 联合配置授权、密钥轮换连续性、成员变更与中断恢复**

## 1. 版本定位

v0.9.0 已证明固定联盟能够跨网络分区、视图切换与提交中断恢复唯一现实。v1.0.0 解决更根本的问题：**维护现实的权威集合本身如何在不停机、不重置历史的前提下安全变化。**

```text
旧配置提出并授权精确转换
→ 新配置独立接受同一转换
→ 轮换主体提供旧/新密钥双证明
→ 联合激活证书先持久化
→ 成员加入、退出、调权、换密钥
→ 中断后恢复同一目标拓扑
→ 旧 epoch、退役成员、旧密钥失效
→ 新配置独立确认当前现实
```

这使 RFE 从“能够恢复现实”进入“**能够连续演化维护现实的权威宪法**”。

## 2. 最简单入口

需要 Node.js 20 或更高版本：

```bash
npm run verify
```

该命令执行：

1. JavaScript 全量语法检查；
2. C7–C12 全部回归与攻击性测试；
3. C12 冻结向量与 C1–C12 总向量哈希验证；
4. 仓库结构、版本、依赖、证据和原生源码静态审计。

原生 Rust 验证需要 Rust/Cargo 1.96：

```bash
npm run verify:native
```

## 4. 冻结能力

- 旧配置和新配置分别满足拜占庭安全权重几何；
- 旧配置法定授权与新配置法定接受缺一不可；
- 成员加入、退出、权重调整和密钥轮换可以在一个原子拓扑转换中完成；
- 密钥轮换需要旧密钥与新密钥对同一转换做双向证明；
- 联合激活证书先于拓扑应用落盘；
- 部分拓扑应用中断后可以幂等恢复；
- 新 epoch 生效后旧 epoch、退役成员和旧密钥立即失效；
- 新配置必须用自己的 quorum 证明其已能够维护当前 reality root。

## 6. 验证边界

JavaScript 参考运行时已在当前环境真实执行并通过 41/41 测试。Rust C12 源码、测试、示例和 workspace 接口已写入，但当前容器没有 Rust/Cargo，因此本发布不会把原生编译或跨运行时等价写成已通过。原生 crate 在本版本定位为**冻结结果的独立结构验证器与持久恢复边界**，并非已证明的独立结果生成器。

## 7. 安全声明

当前 keyed-proof 是确定性一致性适配器，用于冻结协议语义和测试向量，不等同于生产密码学签名。生产部署必须替换为经审计的签名、密钥托管、证书撤销和安全传输实现，同时保持相同的哈希与证书主体边界。
