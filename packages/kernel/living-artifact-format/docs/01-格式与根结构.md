# 格式与证据根

`laf.artifact.v1`包含：

- identity：稳定身份，不随投影变化。
- semantics：字段模式、值、关系与标签。
- authority：角色、作用域和策略引用。
- affordances：主体可以提出的动作，不等于自动获权执行。
- capabilities：对象提供和依赖的能力。
- continuity：Revision、Branch、RFE Generation绑定和Transition引用。
- host_state_refs：HNAC副本快照引用，禁止使用`generation`字段。
- projections：文档、表格、网页、应用、XR等观察者投影定义。
- evidence：语义、权威、能力、投影、Revision和Artifact根。

`artifact_root`不包含evidence自身，避免循环；`revision_root`绑定内容根、父Revision、分支与权威Generation引用。
