# Living Artifact Format 1.0 宪法

## 一、对象边界

Living Artifact 是持续存在的语义对象，不是静态文件，也不是应用进程。

它统一携带：稳定身份、语义、关系、权威边界、可供性、能力声明、局部修订、RFE Generation 引用、宿主状态引用、投影与证据。

## 二、三种连续性不得混淆

- `artifact_revision`：工件内部修订，可在本地和分支中产生。
- `snapshot_sequence`：HNAC宿主副本状态，只描述某设备或运行时。
- `RFE Generation`：唯一能够声明“权威现实已改变”的代际。

LAF不得自行制造RFE Generation。工件只能通过已提交的RNCS Transition Envelope绑定Generation。

## 三、修改边界

LAF运行时可直接生成局部Revision，但正式现实修改必须：提议 → 权威判断 → RFE提交 → Generation绑定。

## 四、哈希边界

采用与RNCS Core Contract一致的UTF-8键排序确定性JSON；核心哈希禁止浮点数，使用整数或十进制定点字符串。
