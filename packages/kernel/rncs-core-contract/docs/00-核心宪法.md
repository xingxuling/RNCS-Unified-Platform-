# RNCS Core Contract v0.1 核心宪法

## 唯一上位连续性

只有 **RFE Generation** 可以声明“权威现实已经改变”。

| 局部结构 | 正式等级 | 能否声明全局现实改变 |
|---|---|---|
| Living Artifact Revision | object_revision | 否 |
| HNAC Snapshot / Replica Revision | replica_snapshot | 否 |
| ICAR Session | execution_session | 否 |
| RSR Simulation Snapshot | simulation_snapshot | 否 |
| VSR Display State | projection_state | 否 |
| Reality Studio Project Revision | authoring_revision | 否 |
| RFE Generation | authoritative_generation | **是** |

## Transition Envelope

每一次候选现实变化必须表达：

`主体 → 意图 → 能力计划 → 权威判断 → 候选变化 → 因果依据 → 证据 → Generation → 投影`

投影可以在提交后继续增加，但不能回写或伪造已经冻结的 Commit Root。

## 禁止事项

1. 宿主快照不得使用 `generation` 字段宣称全局代际；统一改为 `snapshot_sequence`。
2. 投影运行时不得独立提交权威现实。
3. 模拟状态默认是 provisional，只有 RFE 提交后才成为现实。
4. 会话、项目修订、文件版本不得与 RFE Generation 平级。
5. 浮点数不得进入跨运行时哈希核心；应使用整数或十进制定点字符串。
