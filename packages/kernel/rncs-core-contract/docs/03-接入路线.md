# 接入路线

1. **ICAR v0.5**：输出 proposed Envelope，不再直接把旧原子收据当作完整现实。
2. **HNAC v0.5.1**：导出 Host State Reference，`generation` 改为 `snapshot_sequence`。
3. **Living Artifact 1.0**：每个 revision 引用 base/result RFE Generation。
4. **RSR**：只输出 provisional_delta 与 causal_basis。
5. **RFE Core SDK**：消费 authorized Envelope 并返回 result_generation。
6. **VSR/AER**：在 committed Envelope 上附加 Projection Reference。
7. **Gateway v0.3**：发现实现、协商版本、路由 Envelope，不复制运行时源码。
