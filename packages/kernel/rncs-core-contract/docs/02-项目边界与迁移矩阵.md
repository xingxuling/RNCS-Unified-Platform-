# 项目边界与迁移矩阵

| 项目 | 输入 Envelope | 输出内容 | 禁止越界 |
|---|---|---|---|
| ICAR | 主体、目标、当前 Generation | Intent、Capability Plan | 不自行创造全局 Generation |
| HNAC/HNAF | Capability Plan、Host Context | 能力执行、Replica Snapshot | Snapshot 不得命名为 Generation |
| Living Artifact | Generation、语义对象 | Object Revision、语义差异 | Revision 不得冒充现实代际 |
| RSR | 当前状态、规则 | Provisional Causal Delta | 模拟结果不得直接生效 |
| RFE | Proposal、Authority Evidence | Commit、Result Generation | 唯一上位提交者 |
| VSR/AER | Committed Generation、Observer | Projection Reference | 投影不得回写权威状态 |
| Reality Studio | 全部契约 | 制造、编辑、验证 | 项目 Revision 仅为制造记录 |

## 旧字段迁移

- HNAC `generation` → `snapshot_sequence`
- ICAR `sessionHash` → evidence/execution session reference
- LAF `revision` → object_revision
- VSR `sequence` → projection/shared cursor；只有有RFE证书时才映射Generation
