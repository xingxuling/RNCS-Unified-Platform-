# Reality Studio v1.6.0-alpha.1 Release Notes

Reality Studio v1.6 adds the live RNCS Character Genome Forge workspace while
preserving the existing Asset Forge, spatial, behavior, UI/input and sequence
workflows.

The new route compiles Character RCL through the offline RAGF reference
Provider, renders generated mesh geometry, exposes identity and evidence roots,
supports editing and recovery operations, and binds the same sealed Character
Asset Family into Anime Forge.

This release carries local API, full Studio-suite and Chrome desktop/mobile
evidence. It does not claim commercial character art, target-device GPU
acceptance, external DCC/provider parity or clean-machine installation proof.
