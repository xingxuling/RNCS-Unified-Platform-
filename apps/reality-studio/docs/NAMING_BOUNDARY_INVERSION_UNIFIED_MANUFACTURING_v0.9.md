# 场景—资产—行为统一制造：命名边界反演 v0.9

## 异常
传统编辑器把场景、资源浏览器、脚本、动画和运行调试分成多个工具边界。开发者拖入一张图后，还要手工创建节点、绑定脚本、配置碰撞、建立动画和保存依赖。

## 反演
“编辑场景”并不是在画布上摆文件，而是把一个持续资产实例化为具有身份、位置、行为、权限和运行状态的现实对象。

```text
资产身份 + 场景关系 + 行为绑定 + 运行状态 + 证据
→ 可持续的世界对象
```

## 新原语
- Asset Record：资产身份、来源、变体、文件和证据。
- Scene Node：资产在某个世界切片中的实例。
- Behavior Binding：场景节点与行为实体之间的双向关系。
- Unified Manufacturing Session：编辑、运行、调试、撤销和导出的共同会话。
- Scene Projection：同一场景面向玩家或调试者的不同投影。

## 验证标准
1. RAGF Continuity Bundle 能直接注册为资产。
2. 拖入资产会创建场景节点，并可自动创建行为实体。
3. 编辑 Transform 会更新行为程序。
4. 行为 Tick 后的位置会回写到场景投影。
5. 撤销、重做、运行、导出共享同一项目根。
6. 玩家与调试投影共享同一现实来源。
