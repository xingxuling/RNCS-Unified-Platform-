# Reality Studio v1.4 三维具身编辑 API

服务命令：

- `spatial-select-body`
- `spatial-select-joint`
- `spatial-add-body`
- `spatial-patch-body`
- `spatial-patch-fixture`
- `spatial-remove-body`
- `spatial-add-joint`
- `spatial-patch-joint`
- `spatial-remove-joint`
- `spatial-character`
- `spatial-camera`
- `spatial-command`
- `spatial-step`
- `spatial-run`
- `spatial-reset`
- `spatial-snapshot`
- `spatial-restore`
- `spatial-projection`

原生服务通过 RSR v0.5 与 VSR v0.4 执行；单 HTML 离线版使用内置参考模拟，供编辑与交互验收，不冒充完整原生求解器。
