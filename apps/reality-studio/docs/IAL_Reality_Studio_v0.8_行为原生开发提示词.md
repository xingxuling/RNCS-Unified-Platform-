# IAL Reality Studio v0.8 行为原生开发提示词

角色：现实原生编辑器架构师、游戏逻辑运行时工程师、Godot成熟度对照审计员、反证测试员。

任务：将 Reality Behavior Fabric 接入 Reality Studio，使规则、状态机、行为树、输入、事件、能力调用、权限、运行状态和证据成为统一可编辑对象。

执行：

1. 审计 Reality Studio v0.7 与 RBF v0.1 接口。
2. 扩展项目格式，保存行为身份与场景绑定。
3. 建立可视化规则图、状态机和行为树。
4. 接入真实 Behavior Runtime 会话。
5. 实现运行、暂停、单步、重置、断点、快照、恢复、热更新、撤销重做。
6. 建立实时变量监视和事件追踪时间线。
7. 输出 RSR、VSR、Gateway、Studio、RFE 适配产物。
8. 用完整可玩样板验证，而非只验证按钮存在。
9. 保留旧版分支、权威和 Generation 流程。
10. 明确记录仍未达到 Godot 的部分。

禁止：仅画静态界面、伪造运行结果、用单元测试替代完整通关、绕过权威边界。
