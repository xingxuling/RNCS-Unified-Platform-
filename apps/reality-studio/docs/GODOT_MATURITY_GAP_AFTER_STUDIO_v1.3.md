# Reality Studio v1.3 后的 Godot 成熟度差距

v1.3 补上了传统引擎中最关键但此前较弱的一层：资产导入、重导入、依赖、丢失引用、孤儿资产和构建账本。

## 已缩小

- 通用文件导入入口；
- 稳定资产身份；
- 内容摘要与代际；
- 手动重导入；
- JSON路径依赖发现；
- 场景资产使用图；
- 陈旧、缺失、孤儿和未解析依赖审计；
- 构建产物绑定资产连续性证据。

## 仍显著落后

- 专用格式导入器与重导入选项；
- Aseprite/Tiled/glTF/FBX/字体/音频的深度解析；
- 派生物缓存与增量导入；
- 文件系统监听和自动热重导入；
- Import Dock式参数编辑；
- 资源预览生成、缩略图缓存和搜索；
- 引用替换、依赖反查与批量修复；
- 大型项目资产数据库性能；
- 插件化导入器生态。

## 估计影响

这次升级主要提高二维项目的生产可用性，而不是增加视觉上限。相对Godot的能力表面覆盖可小幅上升，但生产成熟度提升更有价值：从“能放入样板资产”推进到“能够管理资产变化”。
