# Reality Studio 行为编辑器命名边界反演 v0.8

## 旧边界

传统“脚本编辑器”默认开发者编辑代码文件；“状态机编辑器”和“行为树编辑器”又被分割成不同工具。

## 异常

同一个玩法变化常被拆成输入、脚本、动画事件、AI树、任务系统、网络权限和存档逻辑。开发者需要人工保证它们描述的是同一件事。

## 反演

行为制造不是编辑脚本，而是编辑：

```text
主体 + 输入 + 事件 + 条件 + 状态 + 决策 + 能力 + 权限 + 因果证据
```

规则图、状态机、行为树和代码只是同一行为现实的不同投影。

## v0.8 落地

- 同一 Program Root 驱动所有编辑视图。
- 编辑后通过 Hot Reload 迁移运行状态。
- Play、Pause、Step 和断点操作同一确定性 Runtime。
- Trace 记录规则、迁移、能力决策和提交根。
- 输出 RSR 命令、VSR 投影、Gateway Manifest 和 RFE Delta。

## 反证边界

若图形编辑器只能画图但不能驱动真实 Runtime，或 Runtime 运行结果无法重放与恢复，则本次反演失败。本版本通过会话运行、快照恢复和完整样板通关验证了最小闭环。
