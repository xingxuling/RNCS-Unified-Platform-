# Reality Studio v0.5 → v0.6 迁移说明

## 迁移原则

旧项目不会被粗暴转换成若干 RNCS 事实后丢失原始结构。完整 v0.5 项目会保存在：

```text
experience.legacy_project
```

并声明：

```text
experience.kind = projection-module
experience.legacy_format = reality-studio.project.v0.5
```

## 自动提取

迁移器会创建：

- 原生项目身份；
- 项目所有者主体；
- Living Artifact；
- 场景数与对象数事实；
- `projection:experience-canvas`；
- 旧项目 Source Root；
- 迁移时间与来源版本。

## 不自动推断

迁移器不会假装理解旧项目中所有脚本、物理行为和视觉语义。复杂内容仍需在 Studio 中补充：

- 主体身份；
- 意图；
- 权威政策；
- 事实关系；
- 现实分支；
- 证据要求。
