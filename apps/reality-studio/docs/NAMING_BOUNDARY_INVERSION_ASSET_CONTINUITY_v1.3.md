# 命名边界反演：从“资源文件”到“资产连续体”

## 旧命名边界

“资源文件”默认资产等于某个路径中的字节。路径变化、内容变化、引用变化和构建变化通常由不同工具分别处理。

## 异常

- 同名文件可能不是同一资产；
- 同一资产换路径后会丢失引用；
- 文件已变更但场景仍使用旧派生物；
- 构建产物无法证明使用了哪一代资产；
- 依赖丢失通常在运行或发布时才暴露。

## 反演

```text
文件路径
→ 来源线索

文件内容
→ 当前代际的内容状态

导入动作
→ 资产身份连续性提交

资源引用
→ 现实对象之间的依赖关系

构建清单
→ 资产连续性证据账本
```

## 新定义

资产是：

```text
稳定身份
+ 来源
+ 内容根
+ 代际
+ 依赖
+ 使用关系
+ 审计状态
+ 构建证据
```

## 价值

该结构不是复制传统AssetDatabase，而是把RFE的身份、Generation、Evidence与游戏内容管线连接起来，使资产变化成为可验证现实变化。
