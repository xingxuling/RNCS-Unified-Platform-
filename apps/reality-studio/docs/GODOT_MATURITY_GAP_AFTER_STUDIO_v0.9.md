# v0.9 后与 Godot 的成熟度差距

## 已缩小
- 场景树、资产架和行为调试第一次进入同一工作台。
- 稳定资产身份可实例化为场景节点。
- 场景 Transform 与行为实体双向同步。
- 具备拖放、Inspector、运行、单步、撤销重做和统一导出。

## 仍然缺少
1. 真正 GPU 编辑视口和 WebGPU 执行器。
2. TileMap、导航、UI布局和多场景实例继承。
3. 完整脚本语言、代码编辑器、断点栈和性能分析器。
4. 文件监视、批量导入、资源重导入和大型项目缓存。
5. Web、Windows、Android 正式构建与签名。
6. 插件系统、包管理、模板和生态。
7. 完整3D工作流。

## 工程估算
- Godot 整体传统功能广度：约 34%–40%。
- Godot 整体生产成熟度：约 26%–32%。
- Godot 二维运行核心：约 66%–74%。
- Godot 二维完整生产体验：约 50%–58%。

这些数字是子系统覆盖估算，不是官方基准。
