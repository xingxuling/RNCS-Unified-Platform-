## 性能基线

环境：Node.js v22.16.0，Linux x64，单线程参考实现。

| 操作 | 中位数 | P95 |
|---|---:|---:|
| 880格地图验证 | 0.058 ms | 0.334 ms |
| 写入1000格 | 1.004 ms | 1.830 ms |
| 视觉投影编译 | 0.157 ms | 0.521 ms |
| 碰撞合并 | 0.078 ms | 0.328 ms |
| 导航网格编译 | 0.335 ms | 0.730 ms |
| 100次路径查询 | 42.712 ms | 77.021 ms |
| 导航会话100 Tick | 340.068 ms | 374.640 ms |

路径缓存验收：100 Tick 仅产生 1 次路径查询与 1 个缓存项。

## 边界

数据不等于 Godot C++ 性能，也不包含 GPU 帧时间。当前导航是网格 A*，没有群体避障和多线程导航烘焙。
