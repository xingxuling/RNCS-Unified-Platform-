# Reality Studio v1.1 与 Godot 二维成熟度差距

## 已补齐

- TileMap 四层空间模型；
- 画笔、橡皮、矩形、填充；
- 瓦片合批投影；
- 碰撞矩形烘焙；
- 导航代价网格；
- 动态障碍；
- 确定性 A* 与路径平滑；
- 导航 Agent 与缓存路径；
- 路径可视化、收据与构建清单；
- Studio、Behavior、VSR 与 Build 接口。

## 仍落后 Godot 的关键能力

1. Terrain Set / Autotile / bitmask 地形规则；
2. 无限分块与大型地图流送；
3. Polygon NavMesh 与导航区域连接；
4. RVO/ORCA 群体避障；
5. 导航烘焙后台线程与增量更新；
6. TileSet 图形化切片、动画瓦片和场景瓦片；
7. 完整 UI、输入映射、Profiler 与插件生态。

## 工程估算

- Godot整体传统功能广度：46%–52%；
- 整体生产成熟度：39%–46%；
- 二维运行核心：80%–87%；
- 二维完整生产体验：72%–80%。

这些数字是子系统覆盖估算，不是官方跑分。
