# Reality Studio TileMap 与导航合约 v1.1

## 1. 权威对象

- TileMap 必须具有稳定 `tilemap_id` 与 `tilemap_root`。
- Tileset、视觉层、碰撞层、导航层均属于同一空间对象。
- 每次编辑必须重新密封 TileMap Root 与 Project Root。

## 2. 编辑合约

支持单格绘制、擦除、批量格、矩形与洪泛填充。越界单格写入必须拒绝；批量写入可忽略越界格。Undo/Redo 必须恢复精确项目状态。

## 3. 投影合约

视觉投影可以合并连续同类瓦片以减少绘制项，但不得改变层级、颜色、标签或空间占用。不同质量档可以改变绘制精度，不得删除关键可供性。

## 4. 碰撞合约

碰撞层编译为确定性矩形集合。相同输入必须产生相同 Shape Root。当前合约输出 RSR 适配清单，不声称已经替代完整连续物理求解。

## 5. 导导航合约

导航网格由 TileMap 代价、静态阻挡和动态障碍共同编译。A* 必须确定性；不可达目标必须返回显式 `unreachable`，不得伪造路径。

## 6. 运行时合约

导航 Agent 路径按需计算并缓存。只有目标、地图或障碍条件失效时才重新计算，避免逐 Tick 重复寻路。运行时位置可覆盖场景投影，但不静默改写权威场景源文件。

## 7. 证据合约

每条路径与导航状态必须绑定 TileMap Root、Navigation Root、Path Root 和 Receipt Root。
