# Reality Studio v1.3.0-alpha.1

**资产连续性原生版**

## 新增

- 本地文件与目录资产导入；
- 浏览器嵌入资产导入；
- PNG/JPEG/WebP/GIF/SVG、常用音频、JSON/YAML、Shader、字体与文本识别；
- SHA-256内容寻址与稳定Asset ID；
- 手动单资产和全资产重导入；
- 资产Generation与历史根；
- JSON文件依赖提取；
- 资产依赖图、场景使用图、未解析依赖和孤儿资产；
- 缺失与陈旧源审计；
- 资产连续性账本进入构建导出；
- 工作台导入、重导入和审计入口；
- CLI与权威服务API。
