# 概念 AI v1 — 用 CSL 写的概念级推理引擎

## 是什么

不同于 token 级 LLM，**概念 AI** 把"概念"作为最小操作单位：

- **输入**：自然语言问题（含已声明的概念名/实例名/主体名）
- **状态**：CSL 知识库 IR（概念 + 实例 + 关系 + 规则 + 主体 + 同位链）
- **推理**：7 个判断单元串成的流水线
- **输出**：结构化推理报告 + 可执行行动建议

整个 AI 的"大脑"用 CSL 本身写成（`src/csl/concept-ai-program.ts`），引擎只是流水线调度器（`src/csl/concept-ai.ts`）。

## 7 步思考流水线

| # | 单元 | 层级 | 作用 |
|---|------|------|------|
| 1 | 概念识别 | 母体 | 在知识库中匹配输入对应的概念/实例/主体 |
| 2 | 属性补全 | 显性 | 列出焦点的全部属性及当前取值 |
| 3 | 关系推断 | 显性 | 枚举焦点参与的关系边 |
| 4 | 不变量校验 | 显性 | 执行相关规则 |
| 5 | 阶段定位 | 隐性 | 主体的当前阶段 + 下一可能转移 |
| 6 | 类比迁移 | 隐性 | 在同位链/映射表中找跨域同位条目 |
| 7 | 再生重组 | 微观 | 综合前 6 步给出行动建议 |

## 三档推理深度

- **轻量问答** (0..30)：跑前 2 步
- **常规推理** (30..70)：跑前 4 步
- **深度推理** (70..100)：跑全 7 步

档位由 CSL 的 `档位` 原语声明，运行时根据用户选择截断流水线。

## 怎么跑

```bash
npm install
npm run dev
```

打开浏览器 → 切到「概念 AI」Tab：

1. 选一个示例（如「材料科学」）→ 点「运行」生成 IR
2. 在「概念 AI」Tab 中输入问题，例如：
   - 「PEDOT:PSS 怎么样？」
   - 「创业者A 现在什么阶段？」
   - 「黄帝有哪些同位？」
3. 看 7 步流水线展开

## 怎么改写自己的知识库

1. 在编辑器里写自己的 CSL 代码（参考示例下拉里的 8 个 demo）
2. 点「运行」编译为 IR
3. 切到「概念 AI」Tab 直接对话

知识库越完整（概念有属性、实例有取值、规则覆盖主流程、主体声明阶段），AI 回答越精准。

## 局限 (v1)

- 只做关键词匹配，不做语义理解（v2 计划接 Lovable AI 把"自然语言→概念名"这一步增强）
- 单轮独立，不带跨问题上下文
- 不做跨知识库联合推理
