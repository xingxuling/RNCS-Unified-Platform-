# CSL Playground v0.8 — 离线发行包

## 快速开始

```bash
npm install
npm run dev
```

打开 `http://localhost:8080` 即可使用。

## 这是什么

中文结构语言（Chinese Structured Language，CSL）的浏览器端编译器与运行时。
纯 TypeScript 实现，零后端依赖，所有解析/IR/运行时/概念级 AI 在浏览器内完成。

## 目录结构

```
src/
├── csl/                    # CSL 语言核心
│   ├── lexer.ts            # 词法（中文关键字表）
│   ├── parser.ts           # 语法（递归下降）
│   ├── ir-builder.ts       # AST → IR 折叠
│   ├── runtime.ts          # 规则评估 / 校验 / 阶段推进
│   ├── stage-engine.ts     # 0.3 主权阶段引擎
│   ├── concept-ai.ts       # 概念 AI v1（7 步流水线）
│   ├── concept-ai-v2.ts    # 概念 AI v2（4 阶段 + 长期记忆）
│   ├── types.ts            # AST + IR 类型
│   ├── examples.ts         # 示例注册表
│   └── *-example.ts        # 12 个示例源码
├── components/csl/         # Playground 9 大 Tab 面板
└── pages/CSLPlayground.tsx # 主页面
```

1. **编辑器** — CSL 源码 + 高亮 + 错误定位
2. **AST** — 抽象语法树
3. **本体** — 概念/属性/实例视图
4. **规则** — 规则评估结果
5. **概念AI** — v1 7 步流水线（旧版，保留对比）

## CSL 自举示例

`csl-self-upgrade-example.ts` 用 CSL 0.7 全套原语描述 CSL 自己：
- 6 大引擎对应 6 个代码模块
- 9 个版本作为概念块挂到引擎下
- 命题块 + 关系块编织演进图谱
- 主体 + 阶段转移描述项目时间线
- 判断单元承载"该不该升级"决策

在 Playground 选「CSL 自举 v3」运行 → 切「记忆块 → 升级建议」用「行动」档位
提问"CSL 0.9 应该加什么"，AI 用这套元知识库结构化回答。补丁可一键追加到编辑器闭环验证。

## v0.8 自举闭环（本轮新增）

Lovable 在本轮直接消费了升级器输出的 3 个目标块：

- **v08_概念块版本化** → `types.ts` 加 `version/history/status` 字段，IR 折叠默认 `1.0.0`，UI 卡片显示版本徽章 + 状态徽章（已实施/草案）
- **v08_规则可追溯** → `runtime.ts` 在 `infer` 中收集每条规则触发的 `evidence_chains`，「推理」Tab 可展开「证据链」折叠区，链接到对应命题块/关系块/证据
- **v08_联邦索引** → 新增 `federation.ts` 联邦索引层（命名 IR 快照表 + 跨库查询 API），概念 AI v2 在检索阶段挂钩，记忆块 Tab 顶部增加"知识库"下拉占位

「升级建议」面板新增：
- **应用到编辑器** 按钮：把生成的 CSL 补丁追加到当前编辑器末尾，闭环验证补丁本身是合法 CSL
- **标记已实施** 状态：本地跟踪哪些升级目标已被消费
