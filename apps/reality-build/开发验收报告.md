## 环境边界

当前发布容器具有 Go 与 JDK，但没有 Android SDK 和 Gradle。因此：

- Windows EXE 是当前环境真实编译产物；
- Android APK 自动化由隔离工具链测试覆盖；
- 发布包提供完整 Android 工程与一键构建脚本；
- 不声称本容器已经编译真实 Android SDK APK。
