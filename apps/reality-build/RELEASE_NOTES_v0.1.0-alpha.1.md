# Reality Build Fabric v0.1.0-alpha.1 发布说明

本版本首次将 Reality Studio 统一项目转化为可发布、可校验的多宿主构建产物。

## 冻结能力

- 四目标构建；
- 资产对账和内容寻址；
- 真实行为运行时浏览器编译；
- 增量缓存；
- Target Root 和 Build Receipt；
- 文件篡改检测；
- 独立 Web/Windows 便携体验；
- Android Studio 工程生成。

## 不包含

- 原生 Win32 EXE；
- 已编译或签名 Android APK/AAB；
- macOS、Linux、iOS 和主机发布；
- GPU 原生执行器；
- 商店 SDK 和补丁服务。
