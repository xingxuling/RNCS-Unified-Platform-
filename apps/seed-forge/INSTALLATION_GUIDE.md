# The Seed Engine - 安装指南

## 📱 手机安装（Android / iOS）

### Android 手机

#### 方法 1: Chrome 浏览器（推荐）

1. **打开 Chrome 浏览器**
2. **访问应用地址**（部署后的 URL，例如：`https://your-app.vercel.app`）
3. **等待页面完全加载**
4. **点击浏览器菜单**（右上角三个点 `⋮`）
5. **选择"添加到主屏幕"** 或 **"安装应用"**
6. **确认安装**
   - 会显示应用名称和图标
   - 点击"添加"或"安装"
7. **完成！**
   - 应用图标会出现在主屏幕上
   - 点击图标即可像原生应用一样运行

#### 方法 2: 其他浏览器

- **Firefox**: 菜单 → "添加到主屏幕"
- **Samsung Internet**: 菜单 → "添加到主屏幕"
- **Edge**: 菜单 → "应用" → "安装此站点为应用"

---

### iPhone / iPad

#### Safari 浏览器

1. **打开 Safari 浏览器**
2. **访问应用地址**
3. **点击分享按钮**（底部中间的 `□↑` 图标）
4. **向下滚动，选择"添加到主屏幕"**
5. **编辑名称**（可选）
6. **点击"添加"**
7. **完成！**
   - 应用图标会出现在主屏幕上
   - 点击图标即可运行

**注意**: iOS 只支持 Safari 浏览器安装 PWA

## 💻 电脑安装（Windows / Mac / Linux）

### Chrome 浏览器（推荐）

1. **打开 Chrome 浏览器**
2. **访问应用地址**
3. **查看地址栏右侧**
   - 会出现一个"安装"图标（`⊕` 或 `+`）
   - 或者显示"安装应用"提示
4. **点击"安装"图标**
5. **确认安装**
   - 会显示应用窗口预览
   - 点击"安装"
6. **完成！**
   - 应用会以独立窗口运行
   - 可以在开始菜单/应用程序中找到

### Edge 浏览器

1. **打开 Edge 浏览器**
2. **访问应用地址**
3. **地址栏右侧会出现"应用"图标**
4. **点击"应用" → "安装此站点为应用"**
5. **确认安装**
6. **完成！**

## 🔧 如果无法安装

### 常见问题

#### 1. 没有"添加到主屏幕"选项

**可能原因**:
- 浏览器不支持 PWA
- 应用未正确配置 manifest

**解决方案**:
- 使用最新版本的 Chrome/Safari/Edge
- 确保应用已正确构建和部署
- 检查 manifest.webmanifest 文件是否存在

#### 2. 安装后无法打开

**可能原因**:
- Service Worker 未正确注册
- 缓存问题

**解决方案**:
- 清除浏览器缓存
- 重新安装应用
- 检查控制台错误信息

#### 3. 图标显示不正确

**可能原因**:
- 图标文件缺失或路径错误

**解决方案**:
- 确保 `public/icon-192.png` 和 `public/icon-512.png` 存在
- 检查 manifest.webmanifest 中的图标路径
- 重新构建应用

2. **构建应用**:
   ```bash

   ```

3. **部署到服务器**:

   - GitHub Pages: `npm run deploy`
