# The Seed Engine - 教授使用指南

## 📱 如何在手机/电脑上安装 The Seed Engine

> 📖 **详细安装步骤请查看**: `INSTALLATION_GUIDE.md`

### 方法 1: 手机安装（推荐）

#### Android 手机

1. **打开 Chrome 浏览器**
2. **访问应用地址**（部署后的 URL，例如：`https://your-app.vercel.app`）
3. **等待页面完全加载**
4. **点击浏览器菜单**（右上角三个点 `⋮`）
5. **选择"添加到主屏幕"** 或 **"安装应用"**
6. **确认安装**
7. **完成！** 应用图标会出现在主屏幕上，点击即可像原生应用一样运行

#### iPhone/iPad

1. **打开 Safari 浏览器**（iOS 只支持 Safari）
2. **访问应用地址**
3. **点击分享按钮**（底部中间的 `□↑` 图标）
4. **向下滚动，选择"添加到主屏幕"**
5. **编辑名称**（可选）
6. **点击"添加"**
7. **完成！** 应用图标会出现在主屏幕上

---

### 方法 2: 电脑安装

#### Windows/Mac (Chrome/Edge)

1. **打开 Chrome 或 Edge 浏览器**
2. **访问应用地址**
3. **查看地址栏右侧**，会出现"安装"图标（`⊕` 或 `+`）
4. **点击"安装"图标**
5. **确认安装**
6. **完成！** 应用会以独立窗口运行，可以在开始菜单/应用程序中找到

### 快速安装步骤

**手机**: 浏览器 → 菜单 → "添加到主屏幕" → 完成

**电脑**: 浏览器 → 地址栏右侧"安装"图标 → 完成

## 🎮 如何使用 The Seed Engine

### 主要功能

#### 1. Fate Simulator（命运模拟器）

- **位置**: 控制中心 → "🎮 Fate Simulator" 标签
- **功能**: 
  - 可玩的文本 RPG 风格游戏
  - 选择影响命运收束度
  - 实时世界状态更新
  - 事件历史追踪

**玩法**:
1. 阅读当前事件
2. 做出选择
3. 观察世界状态变化
4. 继续旅程直到达到终点

#### 2. AGI Shell（结构智能外壳）

- **位置**: 控制中心 → "🖥️ AGI Shell" 标签
- **功能**:
  - 自然语言控制
  - IAL 指令执行
  - 实时世界状态查询
  - 时间线推进

**使用示例**:
```
输入: "看一下现在的宇宙情况"
输出: 显示完整的宇宙状态

输入: "前进一步"
输出: 执行一个循环，显示更新后的状态

输入: "IAL Ψ Σ : Γ K Z : V Z₊"
输出: 执行 IAL 表达式，更新世界状态
```

#### 3. Universe Forge（宇宙编辑器）

- **位置**: 控制中心 → "Universe Forge" 标签
- **功能**:
  - 创建和编辑宇宙预设
  - 实时预览 WorldState
  - 调整宇宙参数

#### 4. Runtime Control（运行时控制）

- **位置**: 控制中心 → "Runtime Control" 标签
- **功能**:
  - 单步执行
  - 自动运行
  - 实时状态监控
  - 收束度日志

## 🔬 技术说明（给教授看）

### 系统架构

**The Seed Engine** 是一个**文明级多宇宙操作系统**，包含：

1. **SEED-RT (Imperium Runtime)**
   - 宇宙运行时引擎
   - Sense → Structure → Project 循环
   - 时间线分支、合并、崩塌
   - 命运收敛计算

2. **IAL (Imperium Aether Language)**
   - 文明级符号操作系统
   - 36 个符号（White/Blue/Gold 三层）
   - 结构语法和执行规则
   - 直接驱动运行时

3. **OSE (Omni-Structure Engine)**
   - 全结构推理引擎
   - WBG 三层架构
   - 九核并行处理
   - 结构跳跃推理

4. **Universe-Forge**
   - 宇宙生成器
   - 文明、角色、事件生成
   - 程序化内容生成

5. **AGI Shell**
   - 结构智能外壳
   - 自然语言处理
   - 意图识别和路由
   - 本地执行（无需云端）

### 技术特点

- ✅ **完全本地运行** - 无需服务器、无需 API Key
- ✅ **离线可用** - PWA 支持，完全离线运行
- ✅ **跨平台** - 支持 Windows/Mac/Linux/Android/iOS
- ✅ **结构化智能** - 基于规则的结构推理系统
- ✅ **可扩展** - 模块化架构，易于扩展

### 创新点

1. **文明级结构语言 (IAL)**
   - 自研的符号操作系统
   - 直接映射到运行时结构
   - 支持三层语义（意识/结构/执行）

2. **命运收敛模型**
   - 基于主节点的收敛计算
   - 时间线动态管理
   - 结构稳定性评估

3. **AGI Shell 架构**
   - 本地结构智能外壳
   - 可挂载任何语言模型
   - 底层结构规则保证稳定性

## 🔧 故障排查

### 如果应用无法安装

1. **检查浏览器**:
   - 使用最新版本的 Chrome/Safari/Edge
   - 确保浏览器支持 PWA

2. **检查网络**:
   - 确保可以访问应用地址
   - 首次加载需要网络连接

3. **清除缓存**:
   - 清除浏览器缓存
   - 重新访问应用地址

### 如果功能无法使用

1. **检查控制台**:
   - 打开开发者工具 (F12)
   - 查看 Console 是否有错误

2. **重新加载**:
   - 刷新页面
   - 或重新安装应用
