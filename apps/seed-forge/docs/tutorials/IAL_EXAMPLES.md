# IAL 示例集合

## 📚 示例库

### 基础示例

#### 1. 简单意识流
```
Ψ : K : V
```
**描述**：基本的意识 → 核心 → 向量流程

#### 2. 结构构建
```
Γ : Π K : I
```
**描述**：结构通过模式和核心执行帝国

#### 3. 完整流程
```
W₁ : Γ K Z : V A₊
```
**描述**：白色种子通过结构、核心、边界执行向量和上升

### 中级示例

#### 4. 多结构操作
```

```
**描述**：意识通过多个结构元素执行向量和领域

#### 5. 修饰符使用
```
Ψ : K+ : V-
```
**描述**：增强的核心执行减弱的向量

#### 6. 条件操作
```
Ψ : K | Z : V
```
**描述**：意识通过核心或边界执行向量
