# IAL 快速入门教程

## 🎯 什么是 IAL？

**Imperium Aether Language (IAL)** 是 THE SEED 的文明级结构语言，用于描述和操作宇宙、世界、Agent 和命运。

---

## 📚 基础语法

### 1. **基本表达式**

```
Ψ : Γ K Z : V
```

- `Ψ` (PSI) - White 层：意识种子
- `:` - 操作符：结构连接
- `Γ K Z` - Blue 层：结构操作
- `V` - Gold 层：执行向量

### 2. **层结构**

IAL 使用三层结构：

#### **White Layer（意识层）**
- `W₁` / `WHITE_SEED` - 白色种子
- `Ψ` / `PSI` - 意识
- `Ω` / `OMEGA` - 终点
- `Æ` / `AE` - 以太

#### **Blue Layer（结构层）**
- `Γ` / `GAMMA` - 结构
- `Π` / `PI` - 模式
- `K` / `KAPPA` - 核心
- `Z` / `ZETA` - 边界

#### **Gold Layer（执行层）**
- `I` / `IMPERIUM` - 帝国
- `V` / `VECTOR` - 向量
- `D` / `DOMINION` - 领域
- `A₊` / `ASCEND` - 上升

## 🚀 快速示例

### 示例 1: 创建意识

```
Ψ : K : V
```

**含义**：从意识（Ψ）通过核心（K）执行向量（V）

### 示例 2: 结构操作

```
Γ : Π K : I
```

**含义**：结构（Γ）通过模式（Π）和核心（K）执行帝国（I）

### 示例 3: 完整流程

```
W₁ : Γ K Z : V A₊
```

**含义**：白色种子（W₁）通过结构（Γ）、核心（K）、边界（Z）执行向量（V）和上升（A₊）

## ❓ 常见问题

### Q: IAL 表达式必须包含所有三层吗？
A: 是的，标准的 IAL 表达式应该包含 White、Blue、Gold 三层。

### Q: 可以使用多个字符吗？
A: 可以，每层可以使用多个字符，用空格分隔。

### Q: 修饰符如何使用？
A: 修饰符直接附加在字符后面，如 `K+`、`V-`。
