# The Seed Engine - 快速安装指南

## 🚀 一键安装（最简单）

### 手机安装

1. **打开浏览器**（Chrome/Safari）
2. **访问应用地址**
3. **点击菜单** → **"添加到主屏幕"**
4. **完成！**

### 电脑安装

1. **打开 Chrome/Edge 浏览器**
2. **访问应用地址**
3. **点击地址栏右侧的"安装"图标**
4. **完成！**

---

## 📱 详细步骤

### Android 手机

```
1. 打开 Chrome 浏览器
2. 访问: https://your-app-url.com
3. 点击右上角菜单 (⋮)
4. 选择"添加到主屏幕"
5. 确认安装
6. 完成！
```

### iPhone

```
1. 打开 Safari 浏览器
2. 访问: https://your-app-url.com
3. 点击分享按钮 (□↑)
4. 选择"添加到主屏幕"
5. 确认添加
6. 完成！
```

### Windows/Mac 电脑

```
1. 打开 Chrome 或 Edge 浏览器
2. 访问: https://your-app-url.com
3. 点击地址栏右侧"安装"图标
4. 确认安装
5. 完成！
```
