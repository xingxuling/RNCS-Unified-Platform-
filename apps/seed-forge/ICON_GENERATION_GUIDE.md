## 🚀 三种生成方法

### 方法 1: 使用 HTML 生成器（最简单，推荐）

1. **打开生成器**:
   ```bash
   # 在浏览器中打开
   scripts/generate-icons.html
   ```

2. **生成图标**:
   - 点击"下载 192x192"按钮
   - 点击"下载 512x512"按钮
   - 点击"下载 1024x1024"按钮（可选）

3. **保存文件**:
   - 将下载的文件保存到 `public/` 目录
   - 确保文件名为：`icon-192.png` 和 `icon-512.png`

### 方法 2: 使用 Node.js 脚本（自动化）

1. **安装依赖** (如果需要):
   ```bash
   npm install canvas
   ```

2. **运行脚本**:
   ```bash
   npm run icons:generate
   ```

3. **完成**:
   - 图标会自动生成到 `public/` 目录

### 方法 3: 使用 SVG 转换（最灵活）

1. **使用在线工具**:
   - 访问: https://convertio.co/svg-png/
   - 上传: `public/icon-seed-simple.svg`
   - 选择尺寸：192x192 和 512x512
   - 下载并保存到 `public/` 目录

2. **使用 ImageMagick** (如果已安装):
   ```bash
   magick public/icon-seed-simple.svg -resize 192x192 public/icon-192.png
   magick public/icon-seed-simple.svg -resize 512x512 public/icon-512.png
   ```
