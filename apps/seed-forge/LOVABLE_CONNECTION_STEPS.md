## 🖼️ 详细步骤（带截图说明）

### 步骤 1: 打开 Lovable 项目

1. 访问: https://lovable.dev/projects/19de0b14-1f7e-468f-93f3-c5daedea79e2
2. 登录你的 Lovable 账户（如果需要）

### 步骤 2: 进入设置

1. 点击左侧菜单的 **Settings**（设置）图标
2. 或直接访问: https://lovable.dev/projects/19de0b14-1f7e-468f-93f3-c5daedea79e2/settings

### 步骤 3: 找到 Git Repository 部分

在设置页面中，向下滚动找到 **"Git Repository"** 或 **"Version Control"** 部分。

### 步骤 4: 连接仓库

1. **如果显示 "Not Connected"**:
   - 点击 **"Connect Repository"** 按钮

2. **如果已经连接了其他仓库**:
   - 点击 **"Update Repository"** 或 **"Change Repository"**

3. **输入仓库 URL**:
   ```
   https://github.com/xingxuling/aether-seed-forge.git
   ```

4. **点击 "Connect" 或 "Save"**

### 步骤 5: 授权 GitHub（如果需要）

1. 如果提示需要授权，点击 **"Authorize"** 或 **"Connect to GitHub"**
2. 在 GitHub 授权页面：
   - 确认授权范围（通常是仓库访问权限）
   - 点击 **"Authorize"**
3. 返回 Lovable，应该显示连接成功

### 步骤 6: 验证连接

1. **检查状态**:
   - 应该显示 **"Connected"** 或 **"Synced"**
   - 显示仓库 URL: `https://github.com/xingxuling/aether-seed-forge.git`

2. **等待同步**:
   - 等待几分钟让文件同步
   - 在 Lovable 项目中检查文件是否出现

## 🆘 故障排查

### 问题 1: 找不到 Git Repository 选项

**可能原因**:
- Lovable 项目类型不支持 Git 连接
- 需要升级账户

**解决方案**:
- 检查项目设置中是否有 "Version Control" 或 "Git" 选项
- 联系 Lovable 支持

### 问题 2: 授权失败

**可能原因**:
- GitHub 权限不足
- 仓库访问权限问题

**解决方案**:
- 确保你是仓库的所有者或有写入权限
- 检查 GitHub 授权设置: https://github.com/settings/applications

### 问题 3: 同步不工作

**可能原因**:
- 网络问题
- 仓库 URL 错误

**解决方案**:
- 验证仓库 URL 是否正确
- 检查 GitHub 仓库是否可访问
- 等待几分钟后重试
