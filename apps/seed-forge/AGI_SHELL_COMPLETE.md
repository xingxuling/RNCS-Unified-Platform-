## 🎯 核心功能

### 1. 自然语言处理

**支持的指令**:
- **查询状态**: "看一下现在的宇宙情况" / "当前命运收束度是多少？"
- **推进时间线**: "前进一步" / "推进 5 步"
- **重置宇宙**: "重置宇宙" / "从头再来"
- **帮助**: "help" / "怎么用"

### 2. IAL 指令执行

**支持的格式**:
- `IAL Ψ Σ : Γ K Z : V Z₊`
- `> Ψ Σ : Γ K Z : V Z₊`

**功能**:
- 直接执行 IAL 表达式
- 实时更新世界状态
- 显示执行结果

### 3. 意图路由系统

**意图类型**:
- `STATUS`: 查询世界状态
- `ADVANCE`: 推进时间线
- `RESET`: 重置宇宙
- `HELP`: 显示帮助
- `UNKNOWN`: 未知指令

### 4. 消息系统

**消息角色**:
- `user`: 用户输入
- `agent`: Shell 响应
- `world`: 世界状态信息
- `system`: 系统消息

## 🚀 使用方式

### 1. 启动 AGI Shell

1. 打开控制中心（`/control-center` 或点击 "🎛️ Control" 标签页）
2. 点击 "🖥️ AGI Shell" Tab
3. Shell 自动初始化

### 2. 使用自然语言

**查询状态**:
```
输入: "看一下现在的宇宙情况"
输出: 显示完整的宇宙状态和主线实体信息
```

**推进时间线**:
```
输入: "前进一步"
输出: 执行一个循环，显示更新后的状态

输入: "推进 5 步"
输出: 执行 5 个循环，显示更新后的状态
```

**重置宇宙**:
```
输入: "重置宇宙"
输出: 重置为初始状态
```

### 3. 使用 IAL 指令

**执行 IAL**:
```
输入: "IAL Ψ Σ : Γ K Z : V Z₊"
输出: 
  - 执行 IAL 表达式
  - 显示执行上下文
  - 显示世界状态变化
```

**简化格式**:
```
输入: "> Ψ Σ : Γ K Z : V Z₊"
输出: 同上
```

## 🔧 技术架构

### 核心组件

1. **AGIShellCore**
   - 处理用户输入
   - 路由到对应操作
   - 管理世界状态

2. **intentPolicies**
   - 意图分类
   - 规则路由（可扩展为模型）

3. **AGIShellConsole**
   - UI 组件
   - 消息显示
   - 输入处理

### 数据流

```
用户输入
    ↓
AGIShellCore.processUserInput()
    ↓
意图识别 / IAL 解析
    ↓
执行操作（SEEDRuntime / IAL Bridge）
    ↓
更新世界状态
    ↓
生成响应消息
    ↓
UI 更新
```
