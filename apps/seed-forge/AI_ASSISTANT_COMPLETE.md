- "创建一个意识系统" → `Ψ : K : V`

## 🚀 使用方式

### 自然语言转 IAL
1. 打开 "🤖 AI" 标签页
2. 选择 "自然语言转 IAL"
3. 输入自然语言描述
4. 点击 "转换为 IAL"
5. 查看生成的 IAL 表达式和置信度

### 内容生成
1. 选择 "内容生成" 标签页
2. 输入生成提示
3. 选择生成类型（故事/描述/世界/对话）
4. 点击生成按钮
5. 查看生成的内容

### Agent 对话
1. 选择 "Agent 对话" 标签页
2. 填写 Agent 信息：
   - Agent 名称
   - Agent 性格
   - 情境
3. 点击 "生成对话"
4. 查看生成的对话
