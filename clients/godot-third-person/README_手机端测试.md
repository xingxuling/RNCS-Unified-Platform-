# 灰烬边境 v0.18.4 手机触控修复

## 这次修复了什么

v0.18.3 只有键盘与鼠标输入。Android Godot 编辑器画面两侧出现的大圆圈属于编辑器自己的触控辅助，并不是游戏控制器，因此进入游戏后角色无法正常操作。

v0.18.4 新增游戏内原生触控层：

- 左侧动态虚拟摇杆：移动；推到底自动冲刺。
- 右侧空白区域拖动：旋转第三人称镜头。
- 攻击、闪避、跳跃、锁定、交互、咏唱按钮。
- 火、霜、雷、风、愈五个法术快捷键。
- 多指输入：左手移动时右手仍可转镜头和攻击。
- 打开咏唱面板时自动暂停触控层，关闭后恢复。
- 手机上不再强制捕获鼠标。
- PC端仍保留原键鼠控制。

## 测试方法

1. 解压到全新目录。
2. Android Godot 编辑器或桌面 Godot 4.7 打开 `project.godot`。
3. 运行主项目。
4. 进入世界后：
   - 左下摇杆移动；
   - 右半屏空白位置拖动镜头；
   - 右下按钮战斗。

编辑器底部的 `_EDITOR_GET ... haptic_on_long_press` 是 Android Godot 编辑器自身警告，不是游戏脚本错误。
`position shadows ... Node3D` 只是命名警告，不阻止运行。
