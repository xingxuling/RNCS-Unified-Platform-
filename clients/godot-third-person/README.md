# 灰烬边境 v0.18.3 Godot 4.7 原生工程

## 本版修复

- 修复 `main.gd` 中 `to_enemy` 对 Variant 使用 `:=` 导致的 Godot 4.7 Parse Error。
- 清理所有函数内部危险的 `:=` 自动类型推断。
- 显式标注敌人、锁定目标、距离、方向、连招数组值与投射物向量类型。
- 保留 v0.18.2 的分阶段开放世界流送和启动诊断。

请解压到全新目录，用 Godot 4.7 stable 打开 `project.godot` 后按 F5。

若曾打开旧版本，先删除 `.godot` 目录或运行“清除旧导入缓存并运行.bat”。

# 灰烬边境 v0.18.2 — Godot 4.7 原生工程

本版修复启动诊断界面无限停留问题，并把一次性世界生成改为分阶段世界流送。

## 关键修复

- `Bootstrap` 使用异步场景读取、进度条和双重超时。
- `GameWorld` 不再在 `_ready()` 中同步生成全部世界。
- 出生区域、玩家、环境、敌人、NPC玩家和存档分阶段初始化。
- 树林与岩石改为低多边形 `MultiMeshInstance3D` 批量渲染。
- 节点加入场景树前使用本地 `position`，不再写 `global_position`。
- 启动失败会显示具体阶段并写入 `user://startup_diagnostics.log`。

## 运行

1. 使用 Godot 4.7 stable 打开 `project.godot`。
2. 等待首次导入完成。
3. 按 F6/F5 运行。
4. 正常情况下进度条会依次经过出生区域、玩家、环境、敌人、NPC与存档，然后进入游戏。

如果30秒后仍失败，诊断页会显示具体原因，不会无限等待。

## 从 v0.18.1 升级时

请解压到全新目录。若曾经在同名目录打开旧工程，先运行 `清除旧导入缓存并运行.bat`，避免 `.godot` 导入缓存继续引用旧脚本。
